Mac 语音输入可以离线吗？断网前的准备与还能用的功能

在飞机上、高铁隧道里，或公司不让声音上传的时候，Mac 的语音输入还能用吗？答案看你用的是哪一种。这篇先讲怎么确认内建听写是不是在本机处理，再整理本机模型工具在断网前要准备的事，以及断网后哪些功能照常、哪些会退回本机做法。

我是 Sona Orbit，一个人开发学舌鸟的独立开发者。学舌鸟是我做的免费 Mac 语音输入工具，第 3、4 节拿它当本机模型工具的例子。内建听写的部分照 Apple 官方说明（在 Mac 上听写消息和文件、macOS 功能特色适用范围），Apple Intelligence 的部分照 Foundation Models 开发者文件，查证日期是 2026 年 11 月 18 日。学舌鸟的功能与选单名称以 0.4.20 为准。

1. 先看结论：离线能不能用，看两件事

  1. 识别在哪里做。声音在 Mac 上转成文字，断网照样能打字。声音要送到服务器，断网就停了。
  2. 断网前准备好了没。本机模型要先下载，用到的语言、AI 整理的方式也要先选好。到了没网络的地方才发现少一个文件，就来不及了。

以台湾的国语来说，macOS 内建听写要先假设需要网络。本机模型的语音输入工具，下载好模型就能离线。最保险的做法是出门前把 Wi-Fi 关掉，实际讲几句试试。

2. 内建听写：先确认你的语言在不在设备上处理

Apple 的功能清单把“设备端听写”支持的语言另外列出来。我查的时候，清单里有国语（中国大陆）和粤语（香港），没有国语（台湾）。也就是说，用国语（台湾）听写时，声音会交给 Apple 的服务器处理，断网就不能用。

清单会随 macOS 更新而变，看你自己的 Mac 最准。

  1. 到“苹果”选单 →“系统设置”→“键盘”。
  2. 看“听写”下方的说明文字。它会写你目前语言的语音是在设备上处理，还是送到服务器。
  3. 关掉 Wi-Fi，到备忘录按听写快速键讲一句。有字出来，就是离线可用。

还没打开听写的话，开法和快速键我写在Mac 语音输入怎么开。

3. 本机模型工具：断网前做好四件事

本机模型的语音输入工具，识别都在 Mac 上做。只是模型、语言档要先下载，第一次设置也要网络。以学舌鸟为例，出门前照这四步准备。

  1. 下载语音模型。第一次打开时的引导会请你下载一个模型。之后想换，到“设置 → 说话 → 语音模型与语言”的“管理模型”下载。下载一次就好，识别在这台 Mac 上进行，没有网络也能听写。下载到一半断线，按“重试”会从中断的地方接著下载。
  2. 下载要用的语气模型。语气提醒的中文模型已内建。英文和日文的语气模型要用时才下载，常讲英文或日文的话，先到“设置 → 语气与情境”找到英文或日文语气模型，按“下载”。
  3. 决定 AI 整理要走哪一条路。去掉“嗯、呃”和说到一半的改口，学舌鸟有三种做法，断网时的表现不一样，下一节的表格有整理。
  4. 关掉 Wi-Fi 试一次。按住右 ⌥ ＋ 右 ⌘ 讲一句“测试一下”，放开后字有贴到光标位置，就准备好了。

4. 断网时，哪些功能照常

学舌鸟第一次打开的欢迎画面，就把“在这台 Mac 上就能做（不需要网络）”和“需要 AI”分成两栏。整理成表如下。

功能断网时说明
语音识别照常模型下载好之后在本机识别
中文排版照常标点、中英之间的空格、繁体或简体
词典与历史纪录照常都存在这台 Mac，词典不开 AI 也有效
语气提醒照常中文模型内建；英文、日文要先下载
AI 整理（云端服务的 API key）退回本机结果连不上时会提示，改贴本机处理过的文字
AI 整理（Apple Intelligence）看系统条件用 Apple 的设备端模型，不需要 API key
改写面板（换语气、正式信、翻译）要能连到你选的 AI云端服务断网时不能用

AI 整理有几个细节值得先知道。

  • 没填 API key，学舌鸟会进入本机模式，只在本机去掉独立的“嗯、呃”和重复的字。说到一半改口的那种整理，要靠 AI。
  • 填了云端服务的 key 但断网，浮窗会提示连不上，并贴上本机处理过的结果。字不会不见，只是少了 AI 那一层。
  • 选 Apple Intelligence，学舌鸟呼叫的是 Apple 文件里的设备端模型（SystemLanguageModel），不用填 key。条件是 Apple 芯片、macOS Tahoe（26.0）以上，并在系统设置打开 Apple Intelligence。
  • 自己在 Mac 上跑语言模型的话，“AI 改写”的供应商可以选 Custom，网址默认是本机的 http://localhost:11434/v1，指向你在这台 Mac 上跑的模型服务。

5. 内存不大的 Mac 怎么挑离线模型

离线语音输入的速度，主要看模型多大、你的 Mac 多快。下载的模型只占硬盘空间；只有正在用的那一个会放进内存，闲置一段时间后也会释放。

  • 8 GB 内存、想要快：先用默认的 SenseVoice Small（253 MB），旧一点的 Mac 也跑得顺。
  • 想要中文更准：试 Qwen3-ASR 0.6B（850 MB）。1.7B（1.5 GB）更准，但比较慢、也比较吃内存。
  • 台湾口音、中英夹杂很多：Breeze-ASR-25（1.2 GB）是针对这种说法调整的，但速度是清单里最慢的。

每个模型的错字率和速度比较，我整理在Mac 本机语音识别模型怎么选。人名、术语老是听错，看从词典到专属语音模型的三层解法。想比较其他本机处理的工具，可以看7 款 Mac 语音输入比较。

6. 常见问题

Mac 内建听写可以离线用中文吗？

要看语言。Apple 的功能清单里，设备端听写有国语（中国大陆）和粤语（香港），我在 2026 年 11 月查的时候没有国语（台湾）。实际情况看“系统设置 → 键盘”里“听写”下方的说明文字，或关掉 Wi-Fi 讲一句试试。

学舌鸟第一次使用需要网络吗？

需要。App 和语音模型都要先下载。模型下载好之后，识别在这台 Mac 上进行，没有网络也能听写。

断网时 AI 整理会怎样？

用云端服务的 API key 时，连不上会提示，并改贴本机处理过的文字。选 Apple Intelligence 的话，用的是 Apple 的设备端模型，需要 Apple 芯片、macOS Tahoe（26.0）以上并打开 Apple Intelligence。

离线语音输入的声音会上传吗？

用本机模型识别时，声音只在这台 Mac 上处理。学舌鸟只有用到云端 AI 的时候，才会把那一段文字送到你选的 AI 服务。平常听写、语气提醒都在本机。

8 GB 内存的 Mac 能离线语音输入吗？

可以。默认的 SenseVoice Small 只有 253 MB，反应快、占用少。想要更准可以试 Qwen3-ASR 0.6B（850 MB）。
