用语音输入写程序：对 Claude Code、Cursor、Codex 口述 Prompt 的设置与排障

用 Claude Code、Cursor 或 Codex 写程序时，花最多时间的常常不是写语法，而是把需求、边界条件和修改方向完整交代给 AI。用讲的比打字快，但工程师一开始用语音输入，很快会遇到四个问题：英文术语被听成中文同音字、边想边讲的改口全被贴进去、想整理口语却要付月费，还有切换窗口时字贴错地方。这篇整理我自己在 Mac 上用学舌鸟对 AI 写程序工具口述的设置和排障做法。

我是 Sona Orbit，一个人开发学舌鸟的独立开发者。学舌鸟是我做的免费 Mac 语音输入工具，Mac 版以开源的 Handy（MIT 授权）为基础。文中功能与选单名称以学舌鸟 0.4.19 为准；其他工具的价格沿用我 10 月 31 日查证的Typeless 替代方案比较，各家常会调整，请以官网为准。

1. 先看结论：写程序用的语音输入怎么选

对 AI 写程序工具讲话，跟回消息不太一样：句子里一定夹著英文术语、项目名称和指令，而且常常边想边讲、讲到一半改口。挑工具时可以先看这四条路：

路线代表语音识别在哪去赘字、改口费用
本机识别＋自选 AI学舌鸟、Handy、VoiceInkMac 本机接自己选的 AI 服务（学舌鸟也可以选 Apple Intelligence）学舌鸟、Handy 免费；VoiceInk 买断 25 美元起
云端订阅Wispr Flow、Typeless云端内建免费版每周约 2,000 字；Pro 每月约 15～30 美元
本机模型＋付费功能Superwhisper本机或云端自订模式每月 8.49 美元起，终身 249.99 美元
系统内建macOS 听写部分语言在本机；华语（台湾）不在苹果的本机清单没有，逐字输出免费

每天跟 AI 讲几千字的话，免费版每周约 2,000 字的上限很快就会用完。学舌鸟的识别在本机、没有字数上限；要整理口语才需要接 AI 服务，可以用 Apple Intelligence 或免费的 Gemini key。各工具更完整的比较，请看Typeless 替代方案那篇。

2. 中英夹杂的技术名词怎么识别准

写程序时讲话一定中英夹杂：“帮我看一下 webhook 那支 handler，为什么收到 payload 之后没有写进 Redis？”要让这种句子一次打对，分两步设置。

第一步：选语音模型

在“设置 → 说话 → 语音模型与语言”选模型，按“管理模型”可以下载别的。三个起点：

  • SenseVoice Small（约 250 MB）：最快，学舌鸟标“推荐”的就是它，旧一点的 Mac 也跑得顺。
  • Qwen3-ASR：中文错字最少的一组，1.7B 约 1.5 GB、比较慢；0.6B 是折衷。
  • Breeze-ASR-25：联发科创新基地（MediaTek Research）针对台湾华语和中英夹杂调过，最慢，但比较懂台湾说法。

学舌鸟的“中文排版”会在中文句子里补全形标点、在中英文之间加空格，繁简照你的设置，英文术语前后不用自己补空格。各模型的大小、速度和中文错字率，可以看Mac 本机语音识别模型比较。不确定哪个适合你的口音，可以用“个人化训练”里的“朗读录音”：一轮 10 句、约 2 分钟，念完会告诉你错字率，换个模型再念一轮就能比。

第二步：用词典钉住项目名称和缩写

再大的通用模型，也不认识你自己取的项目代号或刚出来的工具名。学舌鸟的词典是在识别完之后再修正，换模型也照样有效。

  1. 改一次，下一句就记住：贴上之后你把听错的字改对（例如把“Jmini”改成“Gemini”），学舌鸟会记下“原文 → 改后”，放进“个人化训练”等你确认。按“加入词典”，下一句就生效。
  2. 重写一整句不会污染词典：学舌鸟用读音判断哪些是听错、哪些只是你事后换了说法。换说法的不会进词典，也不会拿去训练；判断错可以改。
  3. 一次导入整批术语：在“设置 → 词典与纪录 → 词典”可以按“新增”，也可以导入 CSV（第一栏正确写法、第二栏错法），把数据表名、服务名称一次放进去。开了 AI 整理时，词典也会一起交给 AI，避免整理时又把专有名词改错。

3. 边想边讲的改口，怎么免费整理

对 AI 讲复杂的修改时，很少人能一次讲得很顺。实际上常常是这样：

“呃，帮我把那个 login 的 API 改成……不对，先不要改 login，先去检查 middleware 里面的 token 验证，过期的话回传 401，然后顺便记一笔 log。”

照原话贴进去，你还得自己删掉“呃、不对、先不要改 login”。学舌鸟的“AI 整理口语”会拿掉赘词和讲到一半的改口再贴上，只整理、不加你没说的内容。没设置 AI 时，会改用本机规则做基本整理。

不想为这个功能付月费，有两种免费做法：

  • Apple Intelligence：在“AI 服务”选 Apple Intelligence，不用申请 key，文字也不离开 Mac。需要 macOS Tahoe（26）以上的 Apple 芯片 Mac，并在系统设置里开启 Apple Intelligence。
  • 免费的 Gemini API key：照三分钟申请教学到 Google AI Studio 申请，不用绑信用卡。免费版每分钟、每天都有次数上限，一般听写和改写通常够用；超过时学舌鸟会先贴上本机整理的版本，不会卡住你打字。依 Google 的说明，免费版送出的内容可能被用来改善 Google 的产品，常讲工作机密的话可以改用付费方案或 Apple Intelligence。

想让每次口述都整理成条列，可以在改写面板选“条理分明”并打开“自动取代”，之后面板关著也会直接贴上整理好的版本。费用细节可以看用自己的 API key 要花多少钱。

4. 两种操作节奏：按住说话、轻按持续听

默认快捷键是右手大拇指就按得到的 右 ⌥ ＋ 右 ⌘，有两种用法：

  1. 短指令，按住说话：光标停在 Cursor、Claude Code 的终端或 commit 消息框，按住快捷键说话，放开就贴到光标位置。讲到一半不想送出，按 Esc 取消。
  2. 长段口述，轻按持续听：要边看程序码边口述一整段重构计划时，轻按一下快捷键（0.3 秒内放开），浮窗会留在画面上一直听，每次停顿就先整理贴上一段；讲完再按一下结束。过程中可以切换 App，文字会贴到你最后在输入的栏位。

5. 常见排障：贴不进去、快捷键冲突、蓝牙耳机漏字

工程师的桌面通常比较复杂：外接屏幕、好几个终端、IDE、Raycast、Karabiner-Elements。遇到问题可以照这样查：

有识别出文字，但没有贴进 Cursor 或终端

  • 辅助使用权限：学舌鸟要有“辅助使用”权限才能把文字贴进别的 App。到“系统设置 → 隐私权与安全性 → 辅助使用”确认学舌鸟有开；刚更新完突然贴不进去，先把开关关掉再打开一次。
  • App 没回报光标位置：Codex 和其他 Chromium 架构的 App 有时不回报光标在哪。0.4.14 起，学舌鸟会再问一下，还是不回报就照样贴上，并把文字留在剪贴板，万一没贴进去可以自己贴。请先更新到最新版。
  • 光标不在输入框：焦点停在按钮或清单上时不会贴。文字不会不见，打开“历史纪录”就能复制刚才那句。

按快捷键没反应，或触发了别的软件

Raycast、Alfred、Karabiner-Elements 或 Hyper Key 设置，可能占用了右边的修饰键。到“设置 → 说话 → 快捷键”换成没被占用的组合。选单列出现“快捷键被 Secure Input 阻挡”时，是某个 App（常见是密码栏位或终端的安全输入）暂时锁住了键盘，离开那个栏位就会恢复。

戴 AirPods 时前两个字没录到、音乐变闷

这是 macOS 用蓝牙耳机麦克风时的通病：开始录音要先切换蓝牙通道，常常漏掉开头，耳机里的音乐也会暂时变成低音质。坐在桌前的话，到“设置 → 说话”把麦克风固定选 Mac 内建或桌上的 USB 麦克风，让 AirPods 只负责听，开头就不容易漏字。

6. 常见问题

对 Claude Code 或 Cursor 讲话，我的程序码或声音会被传出去吗？

录音和语音识别都在你的 Mac 上，声音不上传。只有你开了 AI 整理或改写时，识别出来的那段文字才会直接送到你选的 AI 服务，不经过我；选 Apple Intelligence 的话，文字也不离开 Mac。

已经有 OpenAI、Anthropic、OpenRouter 的 key，或自己在本机跑模型，可以接吗？

可以。AI 服务除了 Gemini 和 Apple Intelligence，也支持 OpenAI、Anthropic、Groq、OpenRouter 和自订端点。自己架的本机模型只要提供相容的端点，填上地址和模型 ID 就能用。

写程序时需要开语气提醒吗？

对 AI 下指令通常不需要。提醒出现时可以点“这个 App 不提醒”，终端和 IDE 就不会再跳；切回 Slack、LINE 或 Mail 回同事和客户时，本机的语气模型照样会提醒。

没有右边的 ⌥ 或 ⌘ 的外接键盘怎么办？

到“设置 → 说话 → 快捷键”换成你方便按的组合。
