用自己的 API key，大概要花多少钱？

平常用，一个月大多不到 1 美元；Gemini、Groq、智谱 GLM 还有免费额度。

怎么算的

学舌鸟每整理一句话，会把整理的规则、你的词典和你说的话一起发给 AI，大约 1,000 个 token；AI 返回整理好的句子，大约 40 个 token。下表用「一天说 30 句（一个月约 900 句）」和「一天说 100 句」两种用量来估。

其他会用到 AI 的地方

  • 改写、翻译、比较格式：每次各算一次，费用和整理一句差不多。
  • 语气提醒：判断在手机上完成，不花钱；只有判断要提醒时，才请 AI 写一句替代说法。
  • 有趣的报告：每周、每月各一次，会先问过你才把文字记录发给 AI。

免费额度

免费额度有每分钟和每天的次数上限，超过时学舌鸟会先粘贴手机本地整理的文字，不会中断打字。额度大多隔天恢复。

避免意外花费

多数服务可以在账号页设置用量上限或用量提醒。API key 只存在你的设备上，文字从设备直接发到你选的服务，不经过学舌鸟。

不想用 API key

在支持 Apple 智能的机型和地区，可以选「Apple 内置」，用手机上的模型，免费、文字不离开手机。在中国大陆可以选 DeepSeek、通义千问、Kimi 或智谱 GLM。

价格是 2026 年 11 月查的公开报价（多数取自价格汇总网站），会变动，以各家官网为准。Mac 版用自己的 API key 时，费用算法相同。
