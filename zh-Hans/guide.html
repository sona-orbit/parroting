使用教程

五分钟学会学舌鸟

从第一次说话，到让它越用越懂你。以下是你会用到的所有基本操作。

本页内容开始之前说话AI 整理口语改写语气提醒词典语音识别模型朗读录音语气提醒个性化AI 服务浮窗

开始之前

安装
打开下载的 Parroting-macos-arm64.dmg，把学舌鸟拖进「应用程序」文件夹，再从「应用程序」打开。要从「应用程序」打开，之后才能自动更新。
第一次打开
学舌鸟会引导你在系统设置里允许「麦克风」和「辅助功能」。麦克风用来收音；辅助功能让它把文字粘贴到你正在用的应用。
更新后的第一次
每次更新后第一次启动，语音模型需要准备约 20 秒，之后就不用再等。
隐私
密码输入框和网上银行这类应用，学舌鸟不会读取内容。
遇到问题
到「设置 → 高级 → 关于 → 显示全部」点「回报问题」，写下发生了什么事就能发给我们。可以选择附上日志，发送前已经移除你说的内容和个人资料，也可以先看看会发送哪些内容。

说话

长按：说完松开就粘贴
右 ⌥＋右 ⌘按住说话，松开后，文字直接粘贴到光标所在的位置。适合一两句的短消息。
轻按：浮窗留在屏幕上，一直听
持续听写默认已经开启（在「说话 → 更多设置 → 持续听写」，开关叫「停顿后自动出字」）。轻按一下快捷键（0.3 秒内松开），浮窗会留在屏幕上一直听，你说的话会实时显示在浮窗里。停一下（默认 0.4 秒），就把这一段整理好粘贴，接着继续听；想马上粘贴，点浮窗上的「完成」。中途可以切换应用，文字会粘贴到当下正在输入的位置。再轻按一次结束。适合写长文、边想边说。
讲完再一次粘贴
在「说话 → 更多设置 → 持续听写」里，默认开启：文字先显示在浮窗，停一下才整理好一次粘贴；开了 AI 整理口语，还会顺便去掉口头禅和改口。关掉的话，每说完一句就直接粘贴到输入框，多久算一句可以用「停顿多久送出」调（默认 0.7 秒）。开着的时候，停多久才粘贴可以用「停多久自动粘贴」调（0.3～3 秒）。
讲话时显示字幕
默认开启（设置首页“其他常用开关”也有开关）：讲话时，识别出的字会在浮窗上方一个字一个字出现，按住说话和持续听写都会；还没确定的部分先淡淡地显示。关掉的话，讲话时不显示。
长按和轻按怎么区分
按住超过 0.3 秒就是长按；很快松开就是轻按。两种可以混着用，不用切换模式。
取消
Esc随时取消，不会粘贴。持续听写时还没粘贴的文字会复制到剪贴板；已经切好的段落，也可以在「待找回的录音」里找回来。
粘贴后自动换行
在设置首页“其他常用开关”开启后，每一段结尾会自动换一行，不会帮你按发送。
外接键盘
键盘没有右边的 ⌥ 或 ⌘，到「设置 → 说话 → 快捷键」换成别的组合。

AI 整理口语

去掉口头禅和改口
「AI 整理口语」默认开启（设置首页“AI 与改写面板”可以关），填好 AI key 就会生效，录音浮窗会有彩色边框，表示这段会交给 AI 整理。说「呃，我们三点开会，不对，四点」，粘贴的会是「我们 4 点开会」。数字、人名、否定词不会被改动。
没有 AI key 时
会改用本机规则，去掉单独出现的「嗯、呃」和重复的字，比如「我我明天去」变成「我明天去」。
短句不经过 AI
「AI 改写 → 更多设置 → 速度」的「短句不经过 AI」默认开启（15 字以内算短句，可以改成 25 或 40 字）：很短的一句话不等 AI，直接粘贴本机处理过的文字，大约快 0.5～1 秒。代价是这些短句少了 AI 的小修正，比如重复的字、说错改口。

改写

「✦ 改写」按钮
每次粘贴后，浮窗旁会出现「✦ 改写」约 4 秒，点它就打开改写面板。和 AI 对话时也会出现，方便你先翻译或整理再发送。少于 4 个字、改写面板已经开着、或没有 AI 服务时不会出现。还没说过话就点它，会打开一个空的面板，等你说下一句。
改写面板常驻
在设置首页“AI 与改写面板”打开「改写面板常驻」，面板会一直留在屏幕上。逐句格式每次停顿处理，整篇格式要按「完成」才处理。点「取代」只换文字、面板不关。点 × 或 Esc 关掉面板，常驻开关也会关闭；但如果开着「自动取代」，格式仍会生效。
没有 AI key 时
改写和 AI 整理口语都要先在「AI 改写」页填好 API key。还没填时，这些开关会是灰色的；点一下会提示，点「去设置」就会带你到填 key 的地方。没有 AI 服务时不会出现改写面板，语气提醒照样会显示在浮窗上；AI 服务中途失效时，面板会关闭，「改写面板常驻」也会跟着关掉。
选格式
内置格式依次是 1 语气修正（默认）、2 条理分明、3 翻译、4 会议记录、5 信件格式。选中的格式应用到每一句；再点一次变「只显示」，面板只显示原话、不改写，「自动取代／取代／再改一次」都变灰。选择会在重新启动后保留。
自动取代
逐句（语气修正、条理分明、翻译）每次停顿就改写并粘贴；整篇（会议记录、信件格式和自定义格式默认）说话时只累积字幕，讲完按「完成」才一次粘贴整篇。只粘贴改写结果；关闭面板后仍生效。录音浮窗「持续」旁有绿色「✦ 条理分明」标签，点击打开面板换格式或关闭自动取代。
调语气
「语气修正」使用「情绪温度」和「正式度」两个滑块。
原本的话与结果
面板上方是你原本说的话，可以收起；下方绿框是改写后的结果，可以直接改字。
调整大小与字号
拖面板的边缘或右下角就能放大、拉长，大小和位置会记住。字太小可以按 ⌘＋／⌘－ 调整。
取代
点「取代」换掉刚刚粘贴的文字，不满意可以按 ⌘Z 撤销。也可以点「再改一次」换一个版本。
用数字键选格式
面板开着时按 1～9 选对应格式；再按一次同一个数字就「只显示」。正在改结果的文字时，改用 ⌘1～⌘9。
持续听写时
面板开着、还没动手改之前，原文会自动换成最新说的那一段。点了改写或改过字之后就固定；之后再粘贴新的话，「取代」会改成把结果复制下来，让你自己粘贴，避免换错位置。
我的格式
到「AI 改写 → 改写格式 → 添加格式」，写下名称和写法。「处理方式」可选「逐句／整篇」，自定义格式默认整篇。内置格式也能修改。
会议记录
只写主题和你说过的要点；决议、待办、时间、人物、负责人、期限只在你说过时才加入。任何格式都不加你没说的细节。
条理分明
适合边想边说。把一大段想到哪说到哪的话，整理成有条理的文字：重点放前面，同一个主题放在一起，重复的话和讲到一半放弃的说法去掉，需要时分段或列点，你提到的每个事实都保留。
翻译
自动判断方向：中文、日文或韩文翻成英文，英文翻成中文。
常驻改写：每一句都先翻译或整理
想让每一句话在粘贴前都先翻译、先整理？看常驻改写，有完整步骤和示例。

语气提醒

中文与英文
语气模型逐句判断语言，中英混用也可以。英文同样能提醒伤人、被动攻击或不合场合的随意语气。完全在 Mac 本机运行，无需 API key；英文也能进行个人化语气训练。英文听写搭配 AI 整理与改写，结果会保持英文。
提醒卡
发送前，如果这句话可能伤人，会弹出提醒卡，同时打开改写面板，你可以改写，也可以按原文发送。
判断不对
觉得不需要提醒，就点「判断不对」。这些反馈会积累起来，用来训练属于你的判断。
这个应用不要提醒
在提醒卡上点一下，就把这个应用加入不提醒列表。之后可以在「语气与情境 → 更多设置 → 提醒范围」移除。
提醒范围
在「语气与情境 → 更多设置 → 提醒范围」自己添加不想被提醒的应用。也可以按场景关闭，和 AI 对话时默认不提醒。
太随意的轻提示
场合需要正式、你却说得太随意时，只在角落轻轻提示，不打断你。
持续听写也有提示
语气提示现在在持续听写时也会出现，不只是按住热键说话的时候。和 AI 对话默认是不提示的场景，所以那里不会有提示。

词典

你确认了才会加入
你改过的字不会自动加入词典，而是先列进「个人化训练」的确认列表，比如「原本：王小明 / 改成：王晓明」，你点确认才加入。学舌鸟会用读音区分：读音相近的算“听错”，可以加入词典；读音差很多的算“换说法”，放在自己的分页，不会进词典，也不会拿去训练。判断错了可以改。确认过的会收进“已确认 N 笔”。
自己添加
到「词典与纪录 → 词典 → 添加」，写下正确写法和常见的错误写法。
刚开始多改几次
语音识别默认使用响应最快的本地模型，偶尔会把同音字或英文词识别错。刚开始多改几次，常用的词很快就会写对；也可以在设置里换成更大的模型。
整理词典
可以搜索、排序、批量删除，也能导入和导出 CSV。

语音识别模型

模型怎么选
第一次设置时，从清单挑一个语音识别模型下载，App 里标「推荐」的是 SenseVoice Small（约 250 MB）。识别在你的 Mac 上进行，声音不会上传。各模型的特点、准确度与许可，请看语音识别模型。
换其他模型
到「说话 → 语音模型与语言」点「管理模型」，「可供下载」里还有其他模型，例如 Whisper、Qwen3-ASR。模型越大通常越准，也越慢。
导入自己的模型
到「说话 → 语音模型与语言」点「管理模型」，在「已下载的模型」标题右边点「导入模型…」，选一个 .gguf 文件。学舌鸟会先检查格式，把文件复制进来，再用 Mac 内置的语音念一句来试识别；认得出字才会启用，并自动切换过去。原来的文件之后移走或删掉都没关系。怎么用自己的录音训练，请看〈越用越懂你〉。
用你的朗读录音测一下
“管理模型”窗口最上面的“用你的朗读录音测一下”，会用你的朗读考卷（每五句留一句）在这台 Mac 上测当前的语音模型，显示错字率。导入自己训练的模型前后各测一次，就知道有没有变好。
导入失败时
界面会写出原因，例如「这不是学舌鸟能用的语音识别模型」，你原本在用的模型不受影响。
切回标准版、删除
导入的模型会标「自己导入」，它不支持的功能（例如即时串流）也会写出来。正在用导入的模型时，旁边会有「切回标准版」；不需要了，可以直接删除。

朗读录音

个人识别体检
侧边栏“个人化训练”页最上面的卡片。照稿念几句，每句念完就标出学舌鸟听错的字，一轮结束告诉你错字率。点“开始一轮（10 句，约 2 分钟）”开始。
怎么念
点“开始念”，或按住平常的听写快捷键；停顿 1.5 秒自动结束，也可以点“念完了”。
是谁的错
标出来的字跟原稿读音一样，是学舌鸟选错字，不是你念错。读音差很多的话，可能是你念了别的词，点“我念的字跟稿不一样”改成你说的；如果原稿本身写错、学舌鸟听到的才对，点“学舌鸟听到的才对”。
句子从哪来
你说过的话、你的词典，加上内置句库。念过的不会再出现。
录音留在哪
朗读录音只留在这台 Mac，不受录音保留期限清理，直到你点“删除所有朗读录音”。
拿去训练
卡片上的“导出训练资料…”可以把录音和正确答案打包，在有 NVIDIA 显卡的电脑上训练专属语音模型；学舌鸟本身不训练。步骤请看〈越用越懂你〉。

语气提醒个性化

从哪里进入
在侧边栏“个人化训练”页的“语气提醒个性化”。这里只调整语气提醒的判断，不会改变语音识别；你给过反馈的语言各有一区。语音识别的专属模型请看〈越用越懂你〉。
开始训练
确认满 20 条语气反馈后，就可以点「开始训练」。训练在你自己的 Mac 上进行，数据不会上传。
验收与采用
训练完会先看到验收结果：哪些句子的判断改变了。你觉得可以再点「采用」，随时可以还原到上一版。

AI 服务

在哪里设置
「AI 改写」页的“AI 服务”卡片，选择 AI 服务并在“API 密钥”填入你的 key。key 存在 macOS 钥匙串。
没有 key 时
AI 整理口语改用本机规则；改写不能使用。语气提醒、词典、本地语音识别都照常可用。
完整图文教程
第一次申请？看申请免费的 Gemini API key，四个步骤都有界面说明。
申请 Gemini key：1. 打开页面
用浏览器打开 aistudio.google.com/api-keys，用 Google 账号登录；第一次使用要先同意服务条款。直接打开这个网址最快，从 AI Studio 首页进去容易找不到入口。
2. 创建 key
点右上角「Create API key」，名称和项目都保持默认，再点「Create key」。页面会出现一串以 AIza 开头的文字，点旁边的复制图标。
3. 粘贴到学舌鸟
到「AI 改写」页，在“AI 服务”卡片选 Gemini，把刚才复制的 key 粘贴到“API 密钥”栏。之后忘了也没关系，回到同一个页面随时可以再复制。
4. 额度与费用（可选）
免费额度有每分钟和每天的次数上限，一般听写、改写通常够用。用得多时，可以在 AI Studio 左侧的「Billing」绑定信用卡，上限会放宽；Google 会给新绑卡的账户设每月消费上限，不会突然出现大额账单。

浮窗

移动位置
浮窗可以直接拖到任何位置，位置会被记住。想回到原来的位置，到「语气与情境 → 更多设置 → 录音浮窗」点「回到默认位置」。
