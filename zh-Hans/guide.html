使用教程

五分钟学会学舌鸟

从第一次说话，到让它越用越懂你。以下是你会用到的所有基本操作。

本页内容开始之前说话AI 整理口语改写语气提醒词典语音识别模型个人化训练AI 服务浮窗

开始之前

安装
打开下载的 Parroting-macos-arm64.dmg，把学舌鸟拖进「应用程序」文件夹，再从「应用程序」打开。要从「应用程序」打开，之后才能自动更新。
第一次打开
学舌鸟会引导你在系统设置里允许「麦克风」和「辅助功能」。麦克风用来收音；辅助功能让它把文字粘贴到你正在用的应用。
更新后的第一次
每次更新后第一次启动，语音模型需要准备约 20 秒，之后就不用再等。
隐私
密码输入框和网上银行这类应用，学舌鸟不会读取内容。
遇到问题
到「关于」页点「回报问题」，写下发生了什么事就能发给我们。可以选择附上日志，发送前已经移除你说的内容和个人资料，也可以先看看会发送哪些内容。

说话

长按：说完松开就粘贴
右 ⌥＋右 ⌘按住说话，松开后，文字直接粘贴到光标所在的位置。适合一两句的短消息。
轻按：浮窗留在屏幕上，一直听
持续听写默认已经开启（在「说话」页的「持续听写」，开关叫「停顿后自动出字」）。轻按一下快捷键（0.3 秒内松开），浮窗会留在屏幕上一直听，你说的话会实时显示在浮窗里。停一下（默认 0.4 秒），就把这一段整理好粘贴，接着继续听；想马上粘贴，点浮窗上的「完成」。中途可以切换应用，文字会粘贴到当下正在输入的位置。再轻按一次结束。适合写长文、边想边说。
讲完再一次粘贴
在「持续听写」里，默认开启：文字先显示在浮窗，停一下才整理好一次粘贴；开了 AI 整理口语，还会顺便去掉口头禅和改口。关掉的话，每说完一句就直接粘贴到输入框，多久算一句可以用「停顿多久送出」调（默认 0.7 秒）。开着的时候，停多久才粘贴可以用「停多久自动粘贴」调（0.3～3 秒）。
讲话时显示字幕
默认开启（设置首页也有开关）：讲话时，识别出的字会在浮窗上方一个字一个字出现，按住说话和持续听写都会；还没确定的部分先淡淡地显示。关掉的话，讲话时不显示。
长按和轻按怎么区分
按住超过 0.3 秒就是长按；很快松开就是轻按。两种可以混着用，不用切换模式。
取消
Esc随时取消，不会粘贴。持续听写时还没粘贴的文字会复制到剪贴板；已经切好的段落，也可以在「待找回的录音」里找回来。
粘贴后自动换行
在设置首页开启后，每一段结尾会自动换一行，不会帮你按发送。
外接键盘
键盘没有右边的 ⌥ 或 ⌘，到「设置 → 说话」换成别的组合。

AI 整理口语

去掉口头禅和改口
「AI 整理口语」默认开启（设置首页可以关），填好 AI key 就会生效，录音浮窗会有彩色边框，表示这段会交给 AI 整理。说「呃，我们三点开会，不对，四点」，粘贴的会是「我们 4 点开会」。数字、人名、否定词不会被改动。
没有 AI key 时
会改用本机规则，去掉单独出现的「嗯、呃」和重复的字，比如「我我明天去」变成「我明天去」。
短句不经过 AI
「AI 改写」页的「短句不经过 AI」默认开启（15 字以内算短句，可以调）：很短的一句话不等 AI，直接粘贴本机处理过的文字，大约快 0.5～1 秒。代价是这些短句少了 AI 的小修正，比如重复的字、说错改口。

改写

「✦ 改写」按钮
每次粘贴后，浮窗旁会出现「✦ 改写」约 4 秒，点它就打开改写面板。和 AI 对话时、少于 4 个字、或没有 AI key 时不会出现。
改写面板常驻
在设置首页打开「改写面板常驻」，面板会一直留在屏幕上，不再需要「✦ 改写」按钮；每次说完话，面板就换成最新那一段并自动改写。点「取代」只换文字、面板不关；点 × 或 Esc 收起，下次说话时再出现。
没有 AI key 时
改写和 AI 整理口语都要先在「AI 改写」页填好 API key。还没填时，这些开关会是灰色的；点一下会提示，点「去设置」就会带你到填 key 的地方。
选格式
面板上方可以选「邮件格式、会议纪要、翻译」或你自己的格式，再点一次就取消。每个应用会记住你上次用的格式，比如在邮件里自动选邮件格式。
调语气
用「情绪温度」和「正式度」两个滑块调整。
原本的话与结果
面板上方是你原本说的话，可以收起；下方绿框是改写后的结果，可以直接改字。
调整大小与字号
拖面板的边缘或右下角就能放大、拉长，大小和位置会记住。字太小可以按 ⌘＋／⌘－ 调整。
取代
点「取代」换掉刚刚粘贴的文字，不满意可以按 ⌘Z 撤销。也可以点「再改一次」换一个版本。
用数字键选格式
面板开着时按 1～9 直接选对应的格式，每个格式上都标着数字；再按一次同一个数字就取消。正在改结果的文字时，改用 ⌘1～⌘9。
持续听写时
面板开着、还没动手改之前，原文会自动换成最新说的那一段。点了改写或改过字之后就固定；之后再粘贴新的话，「取代」会改成把结果复制下来，让你自己粘贴，避免换错位置。
我的格式
到「AI 改写 → 改写格式 → 新增格式」，写下名称和要 AI 怎么写。内置格式也可以改，随时可以恢复默认。
翻译
自动判断方向：中文翻成英文，英文翻成中文。

语气提醒

提醒卡
发送前，如果这句话可能伤人，会弹出提醒卡，同时打开改写面板，你可以改写，也可以按原文发送。
判断不对
觉得不需要提醒，就点「判断不对」。这些反馈会积累起来，用来训练属于你的判断。
这个应用不要提醒
在提醒卡上点一下，就把这个应用加入不提醒列表。之后可以在「提醒范围」移除。
提醒范围
在「语气与情境 → 提醒范围」自己添加不想被提醒的应用。也可以按场景关闭，和 AI 对话时默认不提醒。
太随意的轻提示
场合需要正式、你却说得太随意时，只在角落轻轻提示，不打断你。

词典

你确认了才会加入
你改过的字不会自动加入词典，而是先列进「个人化训练」的确认列表，比如「原本：王小明 / 改成：王晓明」，你点确认才加入。这样可以避免把你只是想换个说法的修改，误当成识别错误。
自己添加
到「词典与记录 → 新增」，写下正确写法和常见的错误写法。
刚开始多改几次
语音识别默认使用响应最快的本地模型，偶尔会把同音字或英文词识别错。刚开始多改几次，常用的词很快就会写对；也可以在设置里换成更大的模型。
整理词典
可以搜索、排序、批量删除，也能导入和导出 CSV。

语音识别模型

模型怎么选
第一次设置时，从清单挑一个语音识别模型下载，App 里标「推荐」的是 SenseVoice Small（约 250 MB）。识别在你的 Mac 上进行，声音不会上传。各模型的特点、准确度与许可，请看语音识别模型。
换其他模型
到「说话」页点「管理模型」，「可供下载」里还有其他模型，例如 Whisper、Qwen3-ASR。模型越大通常越准，也越慢。
导入自己的模型
到「说话」页点「管理模型」，在「已下载的模型」标题右边点「导入模型…」，选一个 .gguf 文件。学舌鸟会先检查格式，把文件复制进来，再用 Mac 内置的语音念一句来试识别；认得出字才会启用，并自动切换过去。原来的文件之后移走或删掉都没关系。
导入失败时
界面会写出原因，例如「这不是学舌鸟能用的语音识别模型」，你原本在用的模型不受影响。
切回标准版、删除
导入的模型会标「自己导入」，它不支持的功能（例如即时串流）也会写出来。正在用导入的模型时，旁边会有「切回标准版」；不需要了，可以直接删除。

个人化训练

从哪里进入
侧边栏的「个人化训练」。
开始训练
确认满 20 条语气反馈后，就可以点「开始训练」。训练在你自己的 Mac 上进行，数据不会上传。
验收与采用
训练完会先看到验收结果：哪些句子的判断改变了。你觉得可以再点「采用」，随时可以还原到上一版。

AI 服务

在哪里设置
「AI 改写」页，选择 AI 服务并填入你的 API key。key 存在 macOS 钥匙串。
没有 key 时
AI 整理口语改用本机规则；改写不能使用。语气提醒、词典、本地语音识别都照常可用。
完整图文教程
第一次申请？看申请免费的 Gemini API key，四个步骤都有界面说明。
申请 Gemini key：1. 打开页面
用浏览器打开 aistudio.google.com/api-keys，用 Google 账号登录；第一次使用要先同意服务条款。直接打开这个网址最快，从 AI Studio 首页进去容易找不到入口。
2. 创建 key
点右上角「Create API key」，名称和项目都保持默认，再点「Create key」。页面会出现一串以 AIza 开头的文字，点旁边的复制图标。
3. 粘贴到学舌鸟
到「AI 改写」页，AI 服务选 Gemini，把刚才复制的 key 粘贴到 API key 栏。之后忘了也没关系，回到同一个页面随时可以再复制。
4. 额度与费用（可选）
免费额度有每分钟和每天的次数上限，一般听写、改写通常够用。用得多时，可以在 AI Studio 左侧的「Billing」绑定信用卡，上限会放宽；Google 会给新绑卡的账户设每月消费上限，不会突然出现大额账单。

浮窗

移动位置
浮窗可以直接拖到任何位置，位置会被记住。想回到原来的位置，到「语气与情境」点「回到默认位置」。
