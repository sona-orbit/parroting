匯入前的注意事項

  • 格式：只接受 .gguf，而且要是學舌鳥支援的模型種類，例如 SenseVoice、Whisper、Qwen3-ASR。
  • 授權：用別人的底模訓練出來的模型，仍要遵守原本的授權，例如標示出處、保留模型名稱。
  • 功能：有些模型不支援即時串流或翻譯，匯入後會標示。
  • 來源：只匯入你信任的檔案。試辨識在獨立的程序裡進行，壞掉的檔案不會拖垮學舌鳥。

匯入不會影響這些

  • 你的詞典：辨識後照樣修正。
  • 學舌鳥語氣模型和你的個人化層：跟語音辨識無關。
  • 原本的底模：留在清單裡，隨時切回。
  • 原始檔：已經複製進來，之後搬走或刪掉都沒關係。

進階 · 用自己的聲音訓練

從學舌鳥匯出資料，訓練你自己的模型。

學舌鳥負責提供資料、使用你的模型；訓練要在你自己的電腦上做，需要一些技術能力和 GPU。

在學舌鳥1. 匯出資料「詞典與紀錄」→「我的資料」→「匯出」，得到一個 zip。
在你的電腦2. 配對錄音與文字每一句的紀錄寫著它的錄音檔名，兩者配成一組。
在你的電腦3. 核對正確答案挑出內容正確的句子，錯的改對，不確定的拿掉。
在你的電腦4. 微調底模用底模官方的訓練工具，以少量參數微調，例如 LoRA。
在學舌鳥5. 轉成 .gguf 匯入轉成和底模一樣的 .gguf 格式，再用「匯入模型…」放進來。
1

匯出你的資料

在左側選「詞典與紀錄」，捲到「資料存放位置」，在「我的資料」按「匯出」，選一個位置存 zip。

錄音在這台 Mac 留多久，由設定裡的「錄音保留多久」決定（最近 300 段、3 天、2 週、3 個月或永不刪除）。想累積更多訓練資料，可以設成永不刪除，或記得定期匯出。

zip 裡面有什麼

錄音放在 app/recordings/，每一句的文字紀錄放在 icloud/年份/ 的每日 .jsonl 檔，一行一句。

每一行的 audio 是錄音檔名，raw 是辨識出來的原文，text 是最後貼上的文字。

Parroting/ ├─ icloud/ │ ├─ 2026/ │ │ ├─ 2026-10-16.mac.xxxx.jsonl ← 每一句的文字紀錄 │ │ └─ 2026-10-16.mac.xxxx.md │ └─ parroting-shared.json ← 詞典、我的資料 └─ app/ ├─ recordings/ │ └─ handy-1792…-0001.wav ← 錄音 ├─ history.db ← 最近的歷史 └─ atype.json # .jsonl 的一行 {"audio": "handy-1792…-0001.wav", "raw": "明天下午三點跟學蛇鳥團隊開會", "text": "明天下午 3 點跟學舌鳥團隊開會。"}
3

整理成訓練清單

把錄音和「正確的文字」配成一張清單。raw 是模型聽到的，不一定對；text 經過 AI 整理，可能刪掉贅字、加了標點，也不完全等於你說的話。

最可靠的做法：以 raw 為底，逐句聽過、改成你實際說的字。答案用你想要的字形，例如全部繁體。

# train.csv：錄音, 正確答案 recordings/handy-1792…-0001.wav, 明天下午三點跟學舌鳥團隊開會 recordings/handy-1792…-0002.wav, 這個副檔名要改成 gguf recordings/handy-1792…-0003.wav, 我把它放在 iCloud 的資料夾 # 另外留一份 test.csv，不拿來訓練， # 用來比較訓練前後的錯字率
4

訓練、檢查、匯入

用你選的底模官方提供的訓練工具微調，只調整少量參數，例如 LoRA。訓練完用 test.csv 比較錯字率，也拿一些別人的聲音測，確認沒有變差，再轉成 .gguf 用「匯入模型…」放進學舌鳥。

以我們的測試，大約 30 分鐘、幾百句的錄音就能看到效果，人名、產品名、你的口音最容易改善。

越用越懂你

模型更新了，你的那一層不會不見。

學舌鳥語氣模型更新時

推出新版語氣模型時，學舌鳥會用你存下來的回饋，自動在新版上重新訓練你的個人化層，通過驗收才套用。你不用從頭累積，也隨時可以還原上一版。

換語音辨識底模時

語音辨識是整個換掉，不是疊加。詞典在辨識之後才作用，所以不管用哪個底模，你的詞典都有效。
