使用教學

五分鐘學會學舌鳥

從第一次說話，到讓它越用越懂你。以下是你會用到的所有基本操作。

本頁內容開始之前說話AI 整理口語改寫語氣提醒詞典語音辨識模型個人化訓練AI 服務浮窗

開始之前

安裝
打開下載的 Parroting-macos-arm64.dmg，把學舌鳥拖進「應用程式」資料夾，再從「應用程式」打開。要從「應用程式」打開，之後才能自動更新。
第一次打開
學舌鳥會引導你在系統設定允許「麥克風」和「輔助使用」。麥克風用來收音；輔助使用讓它把文字貼到你正在用的 App。
更新後的第一次
每次更新後第一次啟動，語音模型要準備約 20 秒，之後就不用再等。
隱私
密碼欄位和網路銀行這類 App，學舌鳥不會讀取內容。
遇到問題
到「關於」頁按「回報問題」，寫下發生了什麼事就能送給我們。可以選擇附上紀錄檔，送出前已經移除你說的內容和個人資料，也可以先看看會送出哪些內容。

說話

長按：說完放開就貼上
右 ⌥＋右 ⌘按住說話，放開後，文字直接貼到游標所在的位置。適合一兩句的短訊息。
輕按：浮窗留在畫面，一直聽
持續聽寫預設已經開啟（在「說話」頁的「持續聽寫」，開關叫「停頓後自動出字」）。輕按一下熱鍵（0.3 秒內放開），浮窗會留在畫面上一直聽，你說的話會即時顯示在浮窗裡。停一下（預設 0.4 秒），就把這一段整理好貼上，接著繼續聽；想馬上貼，按浮窗上的「完成」。中途可以切換 App，文字會貼到當下正在輸入的欄位。再輕按一次結束。適合寫長文、邊想邊說。
講完再一次貼上
在「持續聽寫」裡，預設開啟：文字先顯示在浮窗，停一下才整理好一次貼上；開了 AI 整理口語，還會順便拿掉贅字和改口。關掉的話，每講完一句就直接貼進輸入框，多久算一句可以用「停頓多久送出」調（預設 0.7 秒）。開著的時候，停多久才貼上可以用「停多久自動貼上」調（0.3～3 秒）。
講話時顯示字幕
預設開啟（設定首頁也有開關）：講話時，辨識出的字會在浮窗上方一個字一個字出現，按住說話和持續聽寫都會；還沒確定的部分先淡淡地顯示。關掉的話，講話時不顯示。
長按和輕按怎麼分
按住超過 0.3 秒就是長按；很快放開就是輕按。兩種可以混著用，不用切換模式。
取消
Esc隨時取消，不會貼上。持續聽寫時還沒貼上的文字會複製到剪貼簿；已經切好的段落，也可以在「待找回的錄音」找回來。
貼上後自動換行
在設定首頁開啟後，每一段結尾會自動換一行，不會幫你按送出。
外接鍵盤
鍵盤沒有右邊的 ⌥ 或 ⌘，到「設定 → 說話」換成別的組合。

AI 整理口語

拿掉贅詞和改口
「AI 整理口語」預設開啟（設定首頁可以關），填好 AI key 就會生效，錄音浮窗會有彩色邊框，表示這段會交給 AI 整理。說「呃，我們三點開會，不對，四點」，貼上的會是「我們 4 點開會」。數字、人名、否定詞不會被改動。
沒有 AI key 時
會改用本機的規則，拿掉單獨出現的「嗯、呃」和重複的字，例如「我我明天去」變成「我明天去」。
短句不經過 AI
「AI 改寫」頁的「短句不經過 AI」預設開啟（15 字以內算短句，可以調）：很短的一句話不等 AI，直接貼上本機處理過的文字，大約快 0.5～1 秒。代價是這些短句少了 AI 的小修正，例如重複的字、說錯改口。

改寫

「✦ 改寫」按鈕
每次貼上後，浮窗旁會出現「✦ 改寫」約 4 秒，點它就打開改寫面板。跟 AI 對話時、少於 4 個字、或沒有 AI key 時不會出現。
改寫面板常駐
在設定首頁打開「改寫面板常駐」，面板會一直留在畫面上，不再需要「✦ 改寫」按鈕；每次說完話，面板就換成最新那一段並自動改寫。按「取代」只換文字、面板不關。按 × 或 Esc 關掉面板，設定裡的「改寫面板常駐」也會跟著關閉；再打開這個開關，面板就會出現。
沒有 AI key 時
改寫和 AI 整理口語都要先在「AI 改寫」頁填好 API key。還沒填時，這些開關會是灰色的；點一下會提示，按「去設定」就會帶你到填 key 的地方。沒有 AI 服務時不會出現改寫面板，語氣提醒照樣會顯示在浮窗上；AI 服務中途失效時，面板會關閉，「改寫面板常駐」也會跟著關掉。
選格式
面板上方可以選「信件格式、會議記錄、翻譯」或你自己的格式。選中的格式會亮起，之後說的每一句都會套用，持續聽寫也一樣；再點一次就關掉。每個 App 會記住你上次用的格式，例如在 Mail 自動選信件格式。
自動取代
面板最下面的「自動取代」打開後，選了格式時會先改寫（浮窗字幕顯示「改寫中…」或「翻譯中…」），只把改好的結果貼進輸入框。前面沒有輸入框時，結果會複製起來並提示你貼上；改寫失敗時，貼上你原本說的話。
調語氣
用「情緒溫度」和「正式度」兩條拉桿調整。
原本的話與結果
面板上方是你原本說的話，可以收起；下方綠框是改寫後的結果，可以直接改字。
調整大小與字級
拖面板的邊緣或右下角就能放大、拉長，大小和位置會記住。字太小可以按 ⌘＋／⌘－ 調整。
取代
按「取代」換掉剛剛貼上的文字，不滿意可以按 ⌘Z 還原。也可以按「再改一次」換一個版本。
用數字鍵選格式
面板開著時按 1～9 直接選對應的格式，每個格式上都標著數字；再按一次同一個數字就取消。正在改結果的文字時，改用 ⌘1～⌘9。
持續聽寫時
面板開著、還沒動手改之前，原文會自動換成最新講的那一段。按了改寫或改過字之後就固定；之後再貼上新的話，「取代」會改成把結果複製起來，讓你自己貼上，避免換錯位置。
我的格式
到「AI 改寫 → 改寫格式 → 新增格式」，寫下名稱和要 AI 怎麼寫。內建格式也可以改，隨時可以還原預設。
翻譯
自動判斷方向：中文翻成英文，英文翻成中文。

語氣提醒

提醒卡
送出前，如果這句話可能刺傷人，會跳出提醒卡，同時打開改寫面板，你可以改寫，也可以照原文送出。
判斷不對
覺得不需要提醒，就按「判斷不對」。這些回饋會累積起來，用來訓練屬於你的判斷。
這個 App 不要提醒
在提醒卡上按一下，就把這個 App 加進不提醒清單。之後可以在「提醒範圍」移除。
提醒範圍
在「語氣與情境 → 提醒範圍」自己加入不想被提醒的 App。也可以依場景關閉，跟 AI 對話時預設不提醒。
太隨便的輕提示
場合需要正式、你卻說得太隨意時，只在角落輕輕提示，不打斷你。

詞典

你確認了才會加入
你修正過的字不會自動加進詞典，而是先列進「個人化訓練」的確認清單，例如「原本：王小明 / 改成：王曉明」，你按確認才加入。這樣可以避免把你只是想換個說法的修改，誤當成辨識錯誤。
自己新增
到「詞典與紀錄 → 新增」，寫下正確寫法和常見的錯法。
剛開始多修正幾次
語音辨識預設使用反應最快的本機模型，偶爾會把同音字或英文詞聽錯。剛開始多修正幾次，常用的詞很快就會打對；也可以在設定換成較大的模型。
整理詞典
可以搜尋、排序、批次刪除，也能匯入和匯出 CSV。

語音辨識模型

模型怎麼選
第一次設定時，從清單挑一個語音辨識模型下載，App 裡標「推薦」的是 SenseVoice Small（約 250 MB）。辨識在你的 Mac 上進行，聲音不會上傳。各模型的特色、準確度與授權，請看語音辨識模型。
換其他模型
到「說話」頁按「管理模型」，「可供下載」裡還有其他模型，例如 Qwen3-ASR、Breeze-ASR-25、Whisper。模型越大通常越準，也越慢。
匯入自己的模型
到「說話」頁按「管理模型」，在「已下載的模型」標題右邊按「匯入模型…」，選一個 .gguf 檔。學舌鳥會先檢查格式，把檔案複製進來，再用 Mac 內建的語音唸一句來試辨識；認得出字才會啟用，並自動切換過去。原本的檔案之後搬走或刪掉都沒關係。
匯入失敗時
畫面會寫出原因，例如「這不是學舌鳥能用的語音辨識模型」，你原本在用的模型不受影響。
切回標準版、刪除
匯入的模型會標「自己匯入」，它不支援的功能（例如即時串流）也會寫出來。正在用匯入的模型時，旁邊會有「切回標準版」；不需要了，可以直接刪除。

個人化訓練

從哪裡進去
側邊欄的「個人化訓練」。
開始訓練
確認滿 20 筆語氣回饋後，就可以按「開始訓練」。訓練在你自己的 Mac 上進行，資料不會上傳。
驗收與採用
訓練完會先看到驗收結果：哪些句子的判斷改變了。你覺得可以再按「採用」，隨時可以還原上一版。

AI 服務

在哪裡設定
「AI 改寫」頁，選擇 AI 服務並填入你的 API key。key 存在 macOS 鑰匙圈。
沒有 key 時
AI 整理口語改用本機規則；改寫不能使用。語氣提醒、詞典、本機語音辨識都照常可用。
完整圖文教學
第一次申請？看申請免費的 Gemini API key，四步驟都有畫面說明。
申請 Gemini key：1. 打開頁面
用瀏覽器打開 aistudio.google.com/api-keys，以 Google 帳號登入；第一次使用要先同意服務條款。直接開這個網址最快，從 AI Studio 首頁進去容易找不到入口。
2. 建立 key
按右上角「Create API key」，名稱和專案都維持預設，再按「Create key」。畫面會出現一串以 AIza 開頭的文字，按旁邊的複製圖示。
3. 貼進學舌鳥
到「AI 改寫」頁，AI 服務選 Gemini，把剛才複製的 key 貼進 API key 欄。之後忘了也沒關係，回到同一個頁面隨時可以再複製。
4. 額度與費用（選用）
免費額度有每分鐘和每日的次數上限，一般聽寫、改寫通常夠用。用得多時，可以在 AI Studio 左側的「Billing」綁定信用卡，上限會放寬；Google 會替新綁卡的帳戶設每月花費上限，不會突然出現大筆帳單。

浮窗

移動位置
浮窗可以直接拖到任何位置，位置會被記住。想回到原本的位置，到「語氣與情境」按「回到預設位置」。
