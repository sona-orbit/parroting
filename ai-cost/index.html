用自己的 API key，大概要花多少錢？

平常用，一個月大多不到 1 美元；Gemini、Groq、智譜 GLM 還有免費額度。

怎麼算的

學舌鳥每整理一句話，會把整理的規則、你的詞典和你說的話一起送給 AI，大約 1,000 個 token；AI 回傳整理好的句子，大約 40 個 token。下表用「一天說 30 句（一個月約 900 句）」和「一天說 100 句」兩種用量來估。

其他會用到 AI 的地方

  • 改寫、翻譯、比較格式：每次各算一次，費用和整理一句差不多。
  • 語氣提醒：判斷在手機上完成，不花錢；只有判斷要提醒時，才請 AI 寫一句替代說法。
  • 有趣的回報：每週、每月各一次，會先問過你才把文字紀錄送去 AI。

免費額度

免費額度有每分鐘和每天的次數上限，超過時學舌鳥會先貼上手機本機整理的文字，不會中斷打字。額度多半隔天恢復。

避免意外花費

多數服務可以在帳號頁設定用量上限或用量提醒。API key 只存在你的裝置上，文字從裝置直接送到你選的服務，不經過學舌鳥。

不想用 API key

iPhone 15 Pro 以後的機型可以選「Apple 內建」，用手機上的 Apple Intelligence，免費、文字不離開手機。

價格是 2026 年 11 月查的公開牌價（多數取自價格整理網站），會變動，以各家官網為準。Mac 版用自己的 API key 時，費用算法相同。
