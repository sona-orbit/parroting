Mac 語音輸入可以離線嗎？斷網前的準備與還能用的功能

在飛機上、高鐵隧道裡，或公司不讓聲音上傳的時候，Mac 的語音輸入還能用嗎？答案看你用的是哪一種。這篇先講怎麼確認內建聽寫是不是在本機處理，再整理本機模型工具在斷網前要準備的事，以及斷網後哪些功能照常、哪些會退回本機做法。

我是 Sona Orbit，一個人開發學舌鳥的獨立開發者。學舌鳥是我做的免費 Mac 語音輸入工具，第 3、4 節拿它當本機模型工具的例子。內建聽寫的部分照 Apple 官方說明（在 Mac 上聽寫訊息和文件、macOS 功能特色適用範圍），Apple Intelligence 的部分照 Foundation Models 開發者文件，查證日期是 2026 年 11 月 18 日。學舌鳥的功能與選單名稱以 0.4.20 為準。

1. 先看結論：離線能不能用，看兩件事

  1. 辨識在哪裡做。聲音在 Mac 上轉成文字，斷網照樣能打字。聲音要送到伺服器，斷網就停了。
  2. 斷網前準備好了沒。本機模型要先下載，用到的語言、AI 整理的方式也要先選好。到了沒網路的地方才發現少一個檔案，就來不及了。

以台灣的國語來說，macOS 內建聽寫要先假設需要網路。本機模型的語音輸入工具，下載好模型就能離線。最保險的做法是出門前把 Wi-Fi 關掉，實際講幾句試試。

2. 內建聽寫：先確認你的語言在不在裝置上處理

Apple 的功能清單把「裝置端聽寫」支援的語言另外列出來。我查的時候，清單裡有國語（中國大陸）和粵語（香港），沒有國語（台灣）。也就是說，用國語（台灣）聽寫時，聲音會交給 Apple 的伺服器處理，斷網就不能用。

清單會隨 macOS 更新而變，看你自己的 Mac 最準。

  1. 到「蘋果」選單 →「系統設定」→「鍵盤」。
  2. 看「聽寫」下方的說明文字。它會寫你目前語言的語音是在裝置上處理，還是送到伺服器。
  3. 關掉 Wi-Fi，到備忘錄按聽寫快速鍵講一句。有字出來，就是離線可用。

還沒打開聽寫的話，開法和快速鍵我寫在Mac 語音輸入怎麼開。

3. 本機模型工具：斷網前做好四件事

本機模型的語音輸入工具，辨識都在 Mac 上做。只是模型、語言檔要先下載，第一次設定也要網路。以學舌鳥為例，出門前照這四步準備。

  1. 下載語音模型。第一次打開時的引導會請你下載一個模型。之後想換，到「設定 → 說話 → 語音模型與語言」的「管理模型」下載。下載一次就好，辨識在這台 Mac 上進行，沒有網路也能聽寫。下載到一半斷線，按「重試」會從中斷的地方接著下載。
  2. 下載要用的語氣模型。語氣提醒的中文模型已內建。英文和日文的語氣模型要用時才下載，常講英文或日文的話，先到「設定 → 語氣與情境」找到英文或日文語氣模型，按「下載」。
  3. 決定 AI 整理要走哪一條路。去掉「嗯、呃」和說到一半的改口，學舌鳥有三種做法，斷網時的表現不一樣，下一節的表格有整理。
  4. 關掉 Wi-Fi 試一次。按住右 ⌥ ＋ 右 ⌘ 講一句「測試一下」，放開後字有貼到游標位置，就準備好了。

4. 斷網時，哪些功能照常

學舌鳥第一次打開的歡迎畫面，就把「在這台 Mac 上就能做（不需要網路）」和「需要 AI」分成兩欄。整理成表如下。

功能斷網時說明
語音辨識照常模型下載好之後在本機辨識
中文排版照常標點、中英之間的空格、繁體或簡體
詞典與歷史紀錄照常都存在這台 Mac，詞典不開 AI 也有效
語氣提醒照常中文模型內建；英文、日文要先下載
AI 整理（雲端服務的 API key）退回本機結果連不上時會提示，改貼本機處理過的文字
AI 整理（Apple Intelligence）看系統條件用 Apple 的裝置端模型，不需要 API key
改寫面板（換語氣、正式信、翻譯）要能連到你選的 AI雲端服務斷網時不能用

AI 整理有幾個細節值得先知道。

  • 沒填 API key，學舌鳥會進入本機模式，只在本機去掉獨立的「嗯、呃」和重複的字。說到一半改口的那種整理，要靠 AI。
  • 填了雲端服務的 key 但斷網，浮窗會提示連不上，並貼上本機處理過的結果。字不會不見，只是少了 AI 那一層。
  • 選 Apple Intelligence，學舌鳥呼叫的是 Apple 文件裡的裝置端模型（SystemLanguageModel），不用填 key。條件是 Apple 晶片、macOS Tahoe（26.0）以上，並在系統設定打開 Apple Intelligence。
  • 自己在 Mac 上跑語言模型的話，「AI 改寫」的供應商可以選 Custom，網址預設是本機的 http://localhost:11434/v1，指向你在這台 Mac 上跑的模型服務。

5. 記憶體不大的 Mac 怎麼挑離線模型

離線語音輸入的速度，主要看模型多大、你的 Mac 多快。下載的模型只占硬碟空間；只有正在用的那一個會放進記憶體，閒置一段時間後也會釋放。

  • 8 GB 記憶體、想要快：先用預設的 SenseVoice Small（253 MB），舊一點的 Mac 也跑得順。
  • 想要中文更準：試 Qwen3-ASR 0.6B（850 MB）。1.7B（1.5 GB）更準，但比較慢、也比較吃記憶體。
  • 台灣口音、中英夾雜很多：Breeze-ASR-25（1.2 GB）是針對這種說法調整的，但速度是清單裡最慢的。

每個模型的錯字率和速度比較，我整理在Mac 本機語音辨識模型怎麼選。人名、術語老是聽錯，看從詞典到專屬語音模型的三層解法。想比較其他本機處理的工具，可以看7 款 Mac 語音輸入比較。

6. 常見問題

Mac 內建聽寫可以離線用中文嗎？

要看語言。Apple 的功能清單裡，裝置端聽寫有國語（中國大陸）和粵語（香港），我在 2026 年 11 月查的時候沒有國語（台灣）。實際情況看「系統設定 → 鍵盤」裡「聽寫」下方的說明文字，或關掉 Wi-Fi 講一句試試。

學舌鳥第一次使用需要網路嗎？

需要。App 和語音模型都要先下載。模型下載好之後，辨識在這台 Mac 上進行，沒有網路也能聽寫。

斷網時 AI 整理會怎樣？

用雲端服務的 API key 時，連不上會提示，並改貼本機處理過的文字。選 Apple Intelligence 的話，用的是 Apple 的裝置端模型，需要 Apple 晶片、macOS Tahoe（26.0）以上並打開 Apple Intelligence。

離線語音輸入的聲音會上傳嗎？

用本機模型辨識時，聲音只在這台 Mac 上處理。學舌鳥只有用到雲端 AI 的時候，才會把那一段文字送到你選的 AI 服務。平常聽寫、語氣提醒都在本機。

8 GB 記憶體的 Mac 能離線語音輸入嗎？

可以。預設的 SenseVoice Small 只有 253 MB，反應快、占用少。想要更準可以試 Qwen3-ASR 0.6B（850 MB）。
