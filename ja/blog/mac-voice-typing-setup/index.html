Macの音声入力の始め方：設定手順・ショートカット・中国語の句読点

Macで話して文字を入力するなら、何もインストールする必要はありません。macOSには「音声入力」があります。初期状態ではオフなので、システム設定で一度オンにします。この記事では、Appleの公式説明に沿って、設定手順、ショートカット、中国語の句読点、使えないときの確認方法をまとめました。最後に、標準の音声入力では足りない場合、別の音声入力ツールを使うために必要な手順も説明します。

私はSona Orbitで、Parrotingを一人で開発している個人開発者です。Parrotingは本サイトの自社製品です。無料のMac用音声入力ツールなので、第6節で取り上げます。標準の音声入力の手順と制限は、Appleの公式説明（「Macでメッセージや書類を音声入力する」（Apple サポート）、「Macで音声入力が正常に機能しない場合」（Apple サポート）、「macOSの機能の提供状況」（Apple））に従っています。確認日は2026年11月16日です。メニューの位置はmacOSのバージョンによって少し異なる場合があります。お使いの画面を確認してください。Parrotingの機能とメニュー名は0.4.20に基づきます。

1. まず結論：3つの手順でオンにする

  1. スイッチをオンにする。Appleメニュー →「システム設定」→ サイドバーの「キーボード」→「音声入力」をオンにし、「有効にする」を押します。
  2. ショートカットと言語を選ぶ。同じ場所に「ショートカット」と「言語」があります。「言語」の横の「編集」を押し、話す中国語を選びます。
  3. 入力欄で試す。メモやメッセージの入力欄にカーソルを置き、ショートカットを押します。カーソルが強調表示されて点滅するか、通知音が聞こえたら話し始めます。話し終えたらEscを押します。

たまに1、2文を入力するだけなら、ここまでで十分です。以下では各手順の詳細と、問題が起きたときの確認方法を説明します。

2. macOS標準の音声入力をオンにする

Appleの説明に沿った手順は次のとおりです。

  1. 画面左上のAppleメニューから「システム設定」を選びます。
  2. 左側のサイドバーで「キーボード」を押します。項目が多いので、下にスクロールする必要があるかもしれません。
  3. 右側の「音声入力」をオンにします。確認画面が出たら「有効にする」を押します。
  4. Siriと音声入力の改善のため、録音を共有するか聞かれる場合があります。共有するなら「録音を共有」、しないなら「今はしない」を押します。どちらを選んでも音声入力は使えます。

あとで変更する場合は、「システム設定 → プライバシーとセキュリティ → 解析と改善」に進みます。スイッチの名前は「Siriと音声入力を改善」です。

macOS 12以前には「システム設定」がありません。同じスイッチは「システム環境設定 → キーボード → 音声入力」にあります。

音声入力が使えなくなる場合があります。Appleの説明によると、「音声コントロール」（声でMac全体を操作するアクセシビリティ機能）がオンの間は、標準の音声入力を使えません。文字の入力は音声コントロールで行います。

3. 開始と停止：ショートカットの設定

音声入力をオンにしたら、次の3つの方法で開始できます。

  • マイクキー。キーボードの最上段にマイクのアイコンがある場合は、1回押して離すと音声入力が始まります。押したままにするとSiriが起動するので、すぐに離してください。
  • 音声入力のショートカット。「キーボード」設定の「音声入力」で、「ショートカット」メニューから選びます。使いたい組み合わせがなければ「カスタマイズ」を選び、キーを押して指定します。Appleが挙げている例はOption + Zです。
  • メニュー。多くのAppでは、メニューバーから「編集 → 音声入力を開始」を選べます。

カーソルが強調表示されて点滅するか、通知音が聞こえたら話し始めます。止める方法は3つあります。Escを押す、マイクキーをもう一度押す、または音声入力のショートカットをもう一度押します。何も押さなくても、30秒間静かにしていると自動で止まります。

Appleシリコン搭載のMacでは、音声入力中も停止せずにキーボードで入力できます。キー入力をやめたら、続けて話せます。

認識結果に青い下線が付いた語は、システムが認識結果を確定できていないことを示します。その語を押して別の候補を選ぶか、直接入力し直せます。

4. 中国語の入力：言語・句読点・改行

中国語を追加する

「キーボード」設定の「音声入力」で、「言語」の横にある「編集」を押し、使いたい言語と地域を選びます。中国語（台湾）と英語など、複数選べます。音声入力中はカーソルの横に現在の言語が表示されます。そこを押すと切り替えられます。キーボードに地球儀キーがあれば、そのキーからも選べます。

音声入力は、現在選んでいる言語として音声を認識します。言語を変えるときは自分で切り替えます。

句読点

Appleの機能一覧では、「自動句読点」は中国語（台湾）に対応しています。読点、句点、疑問符が自動で付きます。不要な場合は、同じ設定欄で「自動句読点」をオフにします。

ほかの記号は、例えば「驚嘆號」（感嘆符）のように声に出します。絵文字も「愛心表情符號」（ハートの絵文字）のように言えます。

改行と段落

声に出す言葉動作
換行（改行）Returnを1回押すのと同じ
新增段落（新しい段落）Returnを2回押すのと同じ

改行や新しい段落は、話し終えて音声入力を終了したときに反映されます。コマンドの全一覧はAppleの「テキストを音声入力するためのコマンド」（Apple サポート）にあります。

音声はアップロードされるか

Appleの機能一覧には、デバイス上の音声入力に対応する言語が別に掲載されています。私が確認したときは、中国語（中国本土）と広東語（香港）はありましたが、中国語（台湾）はありませんでした。そのため、中国語（台湾）で音声入力する場合は、まずネットワーク接続が必要だと考えてください。確実なのは、ご自身のMacで確認することです。音声入力をオンにすると、「キーボード」設定の「音声入力」の下に説明文が表示されます。音声がデバイス上で処理されるか、サーバーに送られるかが書かれています。

6. オフラインや長時間の入力：別のツールを使う

標準の音声入力はインストール不要で、たまに数文を入力するのに向いています。次の場合は、別の音声入力ツールも検討できます。

  • ネットワークがない場所で中国語を音声入力したい。または、音声をMacの外に出したくない。
  • 1文の中で中国語と英語が混ざり、言語を何度も切り替えたくない。
  • 同僚の名前や製品名をよく聞き間違えられるので、正しい表記を登録したい。
  • 「押している間に話し、離すとペーストする」操作を使いたい。

この種のツールには有料と無料のものがあり、Mac用音声入力ツール7つを比較でまとめています。ここでは私が作ったParrotingを例に、設定方法を説明します。標準の音声入力と比べると、権限の許可とモデルのダウンロードという2つの手順が増えます。

  1. インストール。ダウンロードしたdmgを開き、Parrotingを「アプリケーション」フォルダにドラッグします。その後、「アプリケーション」から開きます。
  2. 2つの権限を許可。初回起動時にシステム設定が開くので、「マイク」と「アクセシビリティ」を許可します。マイクは音声の取得に使います。アクセシビリティは使用中のAppへの文字のペーストと、ショートカットの受け取りに使います。
  3. 音声モデルをダウンロード。モデルを選んでダウンロードします。ダウンロードは一度だけです。その後の認識はこのMac上で行われ、ネットワークがなくても音声入力できます。
  4. 試す。案内画面に従ってショートカットを押したまま「測試一下」（少しテストする）と言います。ホットキー、マイク、音声認識、ペーストの4つが動作するか、一度に確認できます。

初期設定のショートカットは右 ⌥ ＋ 右 ⌘です。押している間に話し、離すとカーソル位置に文字がペーストされます。軽く1回押すと音声入力が続き、もう一度軽く押すと終了します。Escでキャンセルできます。外付けキーボードに右側の⌥や⌘がない場合は、「設定 → 話す → ホットキー」で別の組み合わせに変更できます。

7. よくある質問

Macの音声入力はどこでオンにできますか？

Appleメニュー →「システム設定」→ サイドバーの「キーボード」→「音声入力」でオンにし、「有効にする」を押します。macOS 12以前では「システム環境設定 → キーボード → 音声入力」にあります。

キーボードにマイクキーがない場合、どうやって音声入力を始めますか？

「キーボード」設定の「音声入力」で、「ショートカット」メニューからキーの組み合わせを選びます。「カスタマイズ」を選んで、自分で組み合わせを指定することもできます。Appのメニューバーから「編集 → 音声入力を開始」を選ぶ方法もあります。

Mac標準の音声入力で、中国語をオフライン入力できますか？

言語によります。Appleの機能一覧では、デバイス上の音声入力に中国語（中国本土）と広東語（香港）はありますが、私が2026年11月に確認した時点では中国語（台湾）はありませんでした。お使いのMacでは、「キーボード」設定の「音声入力」の下にある説明文を確認してください。

音声入力が途中で止まるのはなぜですか？

Appleの説明によると、30秒間音声が検出されないと自動で停止します。ショートカットかマイクキーをもう一度押すと再開できます。

音声入力をオンにできない、または使えないのはなぜですか？

まず「音声コントロール」がオンになっていないか確認してください。オンの間は標準の音声入力を使えません。そのほか、ショートカットの押し間違い、マイクの選択間違い、ネットワークの切断が考えられます。
