MacBookで広東語を音声入力する方法｜標準機能とローカルモデル

MacBook標準の音声入力は広東語に対応しています。ただし、設定をオンにして、言語を追加する必要があります。この記事では、Appleの説明に沿って広東語（香港）の追加方法と標準中国語との切り替え方を紹介します。ローカルの音声認識モデルを使う場合に、広東語に対応するモデルと繁体字の設定方法も説明します。

私はSona Orbitで、Parrotingを一人で開発している個人開発者です。Parrotingは本サイトの自社製品です。無料のMac音声入力ツールなので、第4、5節で紹介します。標準の音声入力の手順と言語一覧は、Appleの公式説明（「Macでメッセージや書類を音声入力する」（Apple サポート）、「macOSの機能が利用できる地域と言語」（Apple））に基づき、2026年11月に確認しました。モデルのサイズと特徴はParrotingのモデル説明ページと同じ情報です。Parrotingのメニュー名は1.0.6に基づきます。広東語の口語表現「嘅」「咗」「啲」（広東語で使う文字）を出力できるかは、モデルによって異なります。体系的な比較はしていないので、ご自身の声で試してください。

1. まず結論

  • ときどき数文を入力するなら：macOS標準の音声入力で十分です。「システム設定 → キーボード → 音声入力」をオンにします。「言語」の「編集」から広東語（香港）を選んでください。
  • 音声の送信が気になるなら：Appleの機能一覧では、広東語（香港）がデバイス上の音声入力に含まれています。お使いのMacでどう処理されるかは、設定画面の「音声入力」の下にある説明文を確認してください。
  • 押している間だけ話し、離したらペーストしたい場合や、よく使う単語を覚えさせたい場合：ローカルの音声入力ツールを追加できます。SenseVoice SmallやQwen3-ASRなど、広東語に対応するモデルを選びます。

2. 標準の音声入力に広東語（香港）を追加する

  1. 画面左上のAppleメニューから「システム設定」を開きます。
  2. サイドバーで「キーボード」を選び、下にある「音声入力」をオンにします。確認画面が出たら「有効にする」を選びます。
  3. 同じ欄で「言語」の横にある「編集」を選び、広東語（香港）を追加します。すでに使っている標準中国語や英語は残せます。
  4. 「ショートカット」メニューで音声入力を開始するキーを選びます。キーボードの最上段にマイクキーがあれば、押して離すことでも開始できます。押し続けるとSiriが起動します。

macOS 12以前では、「システム環境設定 → キーボード → 音声入力」に同じ設定があります。

Appleはデバイス上の音声入力に対応する言語を別の一覧にまとめています。私が確認したときは、広東語（香港）が含まれていました。この機能には音声モデルのダウンロードが必要とも記されています。広東語を追加した直後は、ダウンロードに少し時間がかかる場合があります。追加後、「キーボード」の設定に戻り、「音声入力」の下の説明文を確認してください。現在選んでいる言語の音声をデバイス上で処理するか、サーバーに送信するかが書かれています。

3. 標準中国語と広東語を切り替える

音声入力は、一度に1つの言語で認識します。複数の言語を選んでいる場合、音声入力を始めるとカーソルの横に現在の言語が表示されます。そこをクリックすると切り替えられます。キーボードに地球儀キーがあれば、それを押して選ぶこともできます。

言語は手動で切り替えます。話した内容に合わせて自動では切り替わりません。話し終えたらEscキーで停止します。30秒間無音が続いても停止します。

音声入力の開始手順、ショートカット、使えないときの確認項目は、Macで音声入力を始める方法にまとめました。

4. 広東語に対応するローカルモデル

別途インストールするローカルの音声入力ツールでは、多くの場合、音声認識モデルを自分で選べます。ダウンロード後はMac上で認識し、ネットワークがなくても使えます。ただし、すべてのモデルが広東語に対応しているわけではありません。Parrotingでダウンロードできるモデルのうち、対応言語に広東語が含まれるものを挙げます。

5. Parrotingで広東語と繁体字を設定する

  1. モデルを選ぶ。Parrotingの「設定」を開き、「話す」ページの「音声モデルと言語」から、前の節の表にある広東語対応モデルを選びます。初めて使うときはダウンロードが必要です。
  2. 言語を選ぶ。「言語」メニューで「Cantonese」を選びます。現在、メニューの言語名は英語です。検索欄に「Can」と入力すると見つかります。「自動」も選べますが、広東語を指定したほうが通常は正確です。
  3. 繁体字か簡体字を選ぶ。同じページの「中国語の字体」で「繁体字」「簡体字」「そのまま」から選べます。認識言語が広東語の場合、繁体字への変換には香港の字形対応が使われます。たとえば「里面」（簡体字表記）は「裏面」（香港の繁体字表記）に変わります。標準中国語の場合は台湾の字形対応が使われます。
  4. 試す。デフォルトのホットキーは右⌥＋右⌘です。押しながら話し、離すとカーソルの位置に文字がペーストされます。

よく聞き間違えられる人名、店名、社内用語は、「辞書と履歴」の個人辞書に追加できます。辞書の使い方と、聞き間違いを段階的に直す方法は、辞書から専用音声モデルまで、誤認識を直す3段階の方法をご覧ください。

7. よくある質問

Mac標準の音声入力は広東語に対応していますか？

はい。「システム設定 → キーボード → 音声入力」をオンにし、「言語」の「編集」から広東語（香港）を選んでください。

Macで広東語を音声入力するにはネットワークが必要ですか？

Appleの機能一覧では、広東語（香港）がデバイス上の音声入力に含まれています。音声モデルの事前ダウンロードが必要とも記されています。お使いのMacでの処理方法は、「キーボード」の設定にある「音声入力」の下の説明文を確認してください。

標準中国語と広東語を両方使えますか？

両方を追加できます。ただし、音声入力は一度に1つの言語で認識します。開始後、カーソルの横に表示される言語をクリックするか、地球儀キーで切り替えてください。

広東語に最も正確なローカルモデルはどれですか？

Parrotingでダウンロードできるモデルでは、Qwen3-ASR 1.7Bが中国語と広東語で最も正確です。ただし、ファイルは1.5 GBで、メモリも多く使います。小さくて速いモデルを使いたいなら、まずSenseVoice Smallを試してください。

Parrotingは広東語を繁体字で出力できますか？

はい。「話す」ページの「中国語の字体」で「繁体字」を選びます。認識言語が広東語の場合は香港の字形対応で変換され、たとえば「里面」（簡体字表記）が「裏面」（香港の繁体字表記）になります。
