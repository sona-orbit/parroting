superwhisperの中国語設定：言語・モデル・繁体字出力

superwhisperは中国語に対応しています。ただし、言語の初期設定は「Automatic」です。中国語を話しても英語になることがあり、モデルの選び方によっては認識が遅く、不正確になることもあります。この記事ではsuperwhisperの公式資料と更新履歴に沿って、言語、音声モデル、繁体字出力の設定を順に説明します。最後に、中国語と英語を混ぜて話す場合の設定と、比較できるほかの選択肢も紹介します。

私はSona Orbitで、Parrotingを一人で開発している個人開発者です。Parrotingは本サイトの自社製品です。Mac向けの音声入力アプリとしてsuperwhisperと同じ分野にあるため、第6節で比較します。superwhisperの機能、モデル、価格については、公式資料に記載された内容だけを扱います（音声モデルの資料、言語の誤判定に関する対処法、モード設定の資料、更新履歴）。確認日は2026年11月17日で、当時のMac版の最新版は3.3.1でした。メニュー名は公式資料の英語表記を使っています。お使いの画面とは多少異なる場合があります。Parrotingについては0.4.20を基準にしています。

1. まず結論：中国語で調整する3か所

  1. 言語。使用中のモードを編集し、「Language」を「Automatic」から中国語に変えます。公式資料では、これを「中国語を話したのに英語になる」問題への最も確実な対処法としています。
  2. 音声モデル。無料プランではWhisperシリーズを使えます。中国語専用のWhisper Large v3 Turbo (Chinese)もあります。Proプランでは、中国語に対応するローカルモデルのCohere Transcribeと、クラウドモデルのS1-Voiceも使えます。
  3. 繁体字。更新履歴には、Whisperモデル向けの実験的な繁体字中国語オプションが記載されています。それでも簡体字になる場合は、「Custom」モードのAIへの指示で、台湾の繁体字による出力を指定できます。

設定を変えたら、入力欄で⌥ Space（Option + Space）を押して、一文話してみてください。以下で各手順を説明します。

2. モードの言語を中国語に変える

superwhisperの設定はモードごとに分かれています。言語、音声モデル、AI処理はモードごとに設定するため、実際に使っているモードの言語を変えます。

  1. superwhisperの設定を開き、サイドバーの「Modes」をクリックします。
  2. 使用中のモードをクリックします。現在有効なモードには、一覧で緑の点が付きます。
  3. 「Voice processing」にある言語設定で、「Automatic」を中国語に変えます。

公式のトラブルシューティングには、言語を「Automatic」にすると、英語以外の音声入力が英語の文字になることがあると書かれています。モデルが話している言語を判定できず、英語として認識してしまうためです。これはAI処理より前の文字起こし段階で起こります。原因を確認するには「History」を開いてください。AI処理前の文字起こし結果を見られます。

選べる言語は、モードで使用する音声モデルによって変わります。モデルを変えた後は言語一覧も変わるため、もう一度確認してください。

中国語と英語を頻繁に切り替える場合、公式資料では中国語用と英語用の2つのモードを作り、必要に応じて切り替える方法を勧めています。モード切り替えのショートカットは⌥ ⇧ K（Option + Shift + K）です。「Activate for apps」を使い、特定のアプリで指定したモードを自動適用することもできます。

3. 中国語に対応する音声モデルを選ぶ

各モードの編集画面には「Voice Model」メニューがあります。ローカルモデルは、先に「Settings → Models library」でダウンロードします。次の表には、公式資料で中国語への対応が明記されているモデルだけを載せています。

選ぶときは、次のように考えるとよいでしょう。

  • 無料プランで、主に中国語を話す場合は、まずWhisper Large v3 Turbo (Chinese)を試します。普段話す文をそれぞれ数回入力し、通常のLarge v3 Turboと比べてください。
  • Proを使っていて、ローカルで処理したい場合は、公式資料で最も精度の高いローカルモデルとされるCohere Transcribeを検討できます。公式テストでの文字誤り率は8.4%です。これは公式の8組のテストデータ全体の結果で、中国語だけの数値ではありません。
  • クラウドを使ってもよく、ダウンロードを省きたい場合は、S1-Voiceを選べます。音声はクラウドで認識されます。公式資料によると、クラウドモデルにはデータを保持しないポリシーが適用されます。

ローカルモデルでは、音声は端末の外に出ません。一度ダウンロードすれば、ネットワーク接続なしでも使えます。公式資料では、新しいハードウェア上での動作が速いと説明されています。

価格について、公式サイトに記載されたProの月払いは月額8.49米ドルです。年払いと買い切りプランの価格は公式サイトで確認してください。無料プランではWhisperモデルを無制限に使えます。

4. 繁体字で出力する：実験的なオプションとAI処理

台湾の利用者がつまずきやすい点です。superwhisperの更新履歴には、繁体字に関する記載が2件あります。

  • バージョン1.45.9（2025年4月15日）で、Whisperモデルに実験的な繁体字中国語の言語オプションが追加されました。
  • バージョン1.46.0（2025年5月27日）で、英語（イギリス）と中国語（繁体字）の言語サポートが追加されました。

現在の公式資料には、このオプションが一覧でどの名前で表示されるか明記されていません。モードの言語一覧で繁体字中国語に当たる項目を探してください。Whisperモデルで使える項目なので、ほかのモデルに切り替えると表示されない場合があります。

選択後も簡体字が混ざる場合は、モードのAI処理で補えます。「Custom」モードを作り、AIへの指示に「常に台湾の繁体字中国語で出力し、翻訳や意味の書き換えはしない」と書きます。公式資料にも、入力言語を維持するなどの要件をカスタムモードのAIへの指示に加えられるとあります。AI処理には言語モデルを使います。各プランで使える言語モデルは公式サイトで確認してください。

5. 中国語と英語を混ぜて話す場合の設定

台湾では「這個 bug 我明天 fix」（このバグは明日直す）のように、中国語の文に英単語を混ぜて話すことがあります。公式資料では、この場合に2つの方法を示しています。

  • ほとんどの時間、1つの言語だけを話す場合は、言語を中国語に固定します。「Automatic」より安定します。
  • 1回の音声入力で2つの言語をよく混ぜる場合は、公式資料では「Automatic」を勧めています。英語ばかりに判定されないよう、「Settings → Vocabulary」に中国語で「中国語の単語も含まれる可能性がある」という意味のヒントを追加します。

公式資料は、「Vocabulary」の一覧を短く保つよう注意しています。単語を追加しすぎると、かえって文字起こしの精度が下がることがあります。ヒントの効果はモデルによって異なります。改善しなければ、言語を固定する設定に戻してください。

判断するには実際に試すのが確実です。普段よく話す中国語と英語が混ざった文を3～5つ選び、両方の設定でそれぞれ数回話して、間違いの少ない方を使ってください。

6. 比較できるほかの選択肢

superwhisperはMac、Windows、iOS、Androidで使え、選べるモデルも多くあります。Macだけを使い、主に中国語を話すなら、次の2つも比較できます。

  • macOS標準の音声入力：無料で、インストールは不要です。中国語（台湾）に対応しています。ただしAppleの機能一覧では、中国語（台湾）はデバイス上の音声入力に対応する言語に含まれていません。ネットワークを使う前提で考えてください。有効にする方法はMacで音声入力を有効にする方法に書いています。
  • Parroting：私が開発している無料のMac音声入力アプリです。右⌥＋右⌘を押しながら話し、離すとカーソル位置にテキストが貼り付けられます。音声はMac上で認識し、SenseVoice、Qwen3-ASR、Breeze-ASRなどのモデルを選べます。「設定 → 話す」にある「中国語の字体」で、出力を繁体字または簡体字に固定できます。AI書き換えの結果にも同じ設定が適用されます。

7. よくある質問

superwhisperは中国語に対応していますか？

対応しています。公式資料によると、多言語対応のWhisperモデルとクラウドのS1-Voiceは100以上の言語に対応しています。ローカルのCohere Transcribeが対応する14言語にも中国語が含まれます。中国語だけを認識するWhisper Large v3 Turbo (Chinese)もあります。

superwhisperで中国語を話すと英語になるのはなぜですか？

言語が「Automatic」に設定され、モデルが言語を誤判定していることが多いです。公式資料では、使用中のモードを編集し、「Language」を中国語に固定する方法を勧めています。「Automatic」を使う必要がある場合は、「Settings → Vocabulary」に、中国語も含まれる可能性があるというヒントを中国語で追加できます。

superwhisperは繁体字で出力できますか？

更新履歴によると、2025年4月と5月にWhisperモデルへ繁体字中国語の言語オプションが追加され、当時は実験的と表示されていました。それでも簡体字になる場合は、「Custom」モードのAIへの指示で台湾の繁体字による出力を指定できます。

無料版でも中国語を使えますか？

使えます。公式サイトによると、無料プランではWhisperモデルを無制限に使えます。中国語専用のWhisper Large v3 Turbo (Chinese)も含まれます。Cohere TranscribeとクラウドモデルにはProが必要です。

superwhisperの中国語認識では音声がアップロードされますか？

選ぶモデルによります。公式資料によると、ローカルモデルでは音声が端末の外に出ず、オフラインでも使えます。クラウドモデルではサーバー上で処理され、データを保持しないポリシーが適用されます。
