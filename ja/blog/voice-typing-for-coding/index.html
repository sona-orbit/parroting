音声入力でコードを書く：Claude Code・Cursor・Codexへの指示とトラブル対策

Claude Code、Cursor、Codexでコードを書くとき、時間がかかるのは構文を書くことより、要件や制約、変更方針をAIに伝えることかもしれません。話すほうが入力は速くても、技術用語が中国語の同音異義語として認識されたり、考えながら言い直した部分まで貼り付けられたりします。話し言葉の整理に月額料金が必要なことや、ウィンドウを切り替えたときに別の場所へ貼り付けてしまうこともあります。この記事では、私がMacでParrotingを使い、AIコーディングツールに音声で指示するときの設定とトラブル対策を紹介します。

私はSona Orbitで、Parrotingを一人で開発している個人開発者です。Parrotingは本サイトの自社製品です。無料のMac音声入力アプリで、Mac版はオープンソースのHandy（MITライセンス）を基にしています。この記事の機能とメニュー名はParroting 0.4.19に基づきます。他のツールの価格は、私が10月31日に確認したTypelessの代替ツール比較に基づきます。価格は変わるため、各公式サイトで確認してください。

1. まず結論：コードを書くための音声入力の選び方

AIコーディングツールに話すのは、メッセージへの返信とは違います。中国語の文に英語の技術用語、プロジェクト名、指示が混ざり、考えながら途中で言い直すこともあります。まずは次の4つの方法を比べてください。

毎日AIに数千語を話すなら、無料版の週約2,000語という上限にはすぐ達します。ParrotingはMac上で認識し、語数制限はありません。話し言葉を整理するときだけAIサービスへの接続が必要です。Apple Intelligenceか無料のGemini APIキーを使えます。詳しい比較はTypelessの代替ツールの記事をご覧ください。

2. 中国語と英語が混ざる技術用語を正確に認識する

中国語でコードについて話すときは、英語も混ざります。「幫我看一下 webhook 那支 handler，為什麼收到 payload 之後沒有寫進 Redis？」（webhookのhandlerがpayloadを受け取ってもRedisに書き込まない理由を調べて、という意味）のような文です。正確に入力するには、2段階で設定します。

ステップ1：音声モデルを選ぶ

「設定 → 話す → 音声モデルと言語」でモデルを選びます。「モデルを管理」から別のモデルもダウンロードできます。選ぶ際の出発点は次の3つです。

  • SenseVoice Small（約250 MB）：最も速いモデルです。Parrotingでは「おすすめ」と表示され、古めのMacでもスムーズに動きます。
  • Qwen3-ASR：この中では中国語の文字の誤りが最も少ないモデルです。1.7Bは約1.5 GBで、動作は遅めです。0.6Bはその中間です。
  • Breeze-ASR-25：MediaTek Researchが台湾で話される中国語と英語の混在に合わせて調整したモデルです。最も遅いものの、台湾特有の言い回しを認識しやすくなっています。

Parrotingの「中国語の組版(全角句読点、中英間のスペース)」は、中国語の文に全角の句読点を入れ、中国語と英語の間にスペースを追加します。繁体字か簡体字かは設定に従います。英語の技術用語の前後に自分でスペースを入れる必要はありません。モデルのサイズ、速度、中国語の文字の誤り率はMac向けローカル音声認識モデルの比較をご覧ください。自分の発音に合うモデルを調べるには、「パーソナライズ学習」の「音読の録音」を使えます。1回10文、約2分の音読で誤り率が分かります。モデルを替えてもう一度読めば比較できます。

ステップ2：辞書にプロジェクト名と略語を登録する

汎用モデルは、自分で付けたプロジェクトのコードネームや新しいツール名を知りません。Parrotingの辞書は音声認識の後に修正するため、モデルを替えても使えます。

  1. 一度直せば、次の文から反映：貼り付け後に聞き間違いを直すと、たとえば「Jmini」を「Gemini」に修正した場合、Parrotingは修正前後を記録し、「パーソナライズ学習」に確認待ちとして表示します。「辞書に追加」を押すと、次の文から反映されます。
  2. 文全体を書き直しても辞書は汚れない：Parrotingは発音を使い、聞き間違いと言い換えを区別します。言い換えた部分は辞書にも学習データにも入りません。判定が違えば修正できます。
  3. 用語をまとめて読み込む：「設定 → 辞書と履歴 → 辞書」では「追加」を押すか、CSVを読み込めます。CSVの1列目に正しい表記、2列目に誤認識された表記を入れます。テーブル名やサービス名をまとめて登録できます。AIによる整理を有効にした場合は辞書もAIに送られ、固有名詞が誤って書き換えられるのを防ぎます。

3. 考えながら話した言い直しを無料で整理する

複雑な変更をAIに説明するとき、最初から順序よく話すのは難しいものです。実際には次のようになりがちです。

「呃，幫我把那個 login 的 API 改成……不對，先不要改 login，先去檢查 middleware 裡面的 token 驗證，過期的話回傳 401，然後順便記一筆 log。」（login APIを変更して、と言いかけて撤回し、まずmiddlewareのtoken検証を確認して、期限切れなら401を返しlogも残すよう指示しています）

そのまま貼り付けると、「呃、不對、先不要改 login」（「ええと」「違う」「loginはまだ変更しない」という言い直し）を自分で削る必要があります。Parrotingの「AIで話し言葉を整える」は、不要な語や途中の言い直しを除いてから貼り付けます。話した内容を整理するだけで、話していない指示は加えません。AIを設定していない場合は、ローカルのルールで基本的な整理をします。

この機能に月額料金を払わずに使う方法は2つあります。

  • Apple Intelligence：「AIサービス」でApple Intelligenceを選びます。APIキーは不要で、テキストもMacの外に出ません。macOS Tahoe（26）以降を搭載したAppleシリコンのMacで、システム設定からApple Intelligenceを有効にする必要があります。
  • 無料のGemini APIキー：3分でできる取得手順に沿ってGoogle AI Studioで取得します。クレジットカードの登録は不要です。無料版には1分あたりと1日あたりの回数制限がありますが、通常の音声入力や書き換えにはおおむね足ります。上限に達した場合、Parrotingはローカルで整理した文を貼り付けるので、入力を続けられます。Googleによると、無料版で送信した内容はGoogle製品の改善に使われる可能性があります。仕事の機密情報をよく話すなら、有料プランかApple Intelligenceを使えます。

毎回の音声入力を箇条書きにしたい場合は、書き換えパネルで「要点を整理」を選び、「自動で置き換え」を有効にします。その後はパネルを閉じていても、整理した文が直接貼り付けられます。費用については自分のAPIキーを使う場合の費用をご覧ください。

4. 押して話す、軽く押して聞き続ける：2つの操作方法

標準のホットキーは、右手の親指で押せる右⌥＋右⌘です。使い方は2つあります。

  1. 短い指示は押して話す：Cursor、Claude Codeのターミナル、またはコミットメッセージ欄にカーソルを置きます。ホットキーを押しながら話し、離すとカーソルの位置に貼り付けられます。途中でやめたいときはEscを押します。
  2. 長い口述は軽く押して聞き続ける：コードを見ながらリファクタリングの計画を話すときは、ホットキーを軽く押し、0.3秒以内に離します。フローティングウィンドウが画面に残って聞き続け、話が途切れるたびに一部分を整理して貼り付けます。終わったらもう一度押します。途中でAppを切り替えることもでき、最後に入力していた欄にテキストが貼り付けられます。

5. 貼り付け、ホットキー、Bluetoothイヤホンのトラブル対策

開発者のデスクトップには、外付けディスプレイ、複数のターミナル、IDE、Raycast、Karabiner-Elementsなどが並びます。問題が起きたら、次の順に確認してください。

文字は認識されるのに、Cursorやターミナルに貼り付けられない

  • アクセシビリティの権限：Parrotingが別のAppに貼り付けるには、アクセシビリティの権限が必要です。「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でParrotingが有効か確認してください。更新直後に貼り付けられなくなった場合は、一度オフにしてから再びオンにします。
  • Appがカーソル位置を返さない：CodexなどChromiumベースのAppは、カーソル位置を返さないことがあります。0.4.14以降、Parrotingは位置を再確認します。それでも返答がなければ貼り付けを試み、テキストをクリップボードにも残します。貼り付けられなかった場合は手動で貼り付けられます。まず最新版に更新してください。
  • カーソルが入力欄にない：ボタンやリストにフォーカスがあると貼り付けられません。テキストは失われないので、「履歴」を開いて直前の文をコピーできます。

ホットキーが反応しない、または別のソフトウェアが起動する

Raycast、Alfred、Karabiner-Elements、Hyper Keyの設定が、右側の修飾キーを使っている可能性があります。「設定 → 話す → ホットキー」で使われていない組み合わせに変更してください。メニューバーに「ホットキーがSecure Inputによってブロックされています」と出る場合は、別のAppが一時的にキーボード入力を制限しています。パスワード欄やターミナルの安全な入力が主な原因です。その欄から離れると使えるようになります。

AirPods使用時に最初の2語が録音されない、音楽がこもる

Bluetoothイヤホンのマイクを使うときによく起きるmacOSの問題です。録音開始時にBluetoothの通信経路が切り替わるため、冒頭が欠けることがあります。イヤホンで聞く音楽の音質も一時的に下がります。デスクで使うなら、「設定 → 話す」でMac内蔵マイクかデスク上のUSBマイクを固定して選び、AirPodsは聞くためだけに使ってください。冒頭の語が欠けにくくなります。

6. よくある質問

Claude CodeやCursorに話すと、コードや音声は外部に送られますか？

録音と音声認識はどちらもMac上で行われ、音声はアップロードされません。AIで話し言葉を整えたり書き換えたりする場合だけ、認識されたテキストが選んだAIサービスに直接送られます。私を経由しません。Apple Intelligenceを選べば、テキストもMacの外に出ません。

OpenAI、Anthropic、OpenRouterのAPIキーや、ローカルで動かすモデルは使えますか？

使えます。AIサービスはGeminiとApple Intelligenceのほか、OpenAI、Anthropic、Groq、OpenRouter、カスタムエンドポイントに対応しています。ローカルモデルが互換性のあるエンドポイントを提供していれば、URLとモデルIDを入力して使えます。

コードを書くとき、口調ヒントを有効にする必要はありますか？

AIへの指示には通常必要ありません。ヒントが出たら「このAppでは通知しない」を選ぶと、ターミナルやIDEでは表示されなくなります。Slack、LINE、Mailに切り替えて同僚や顧客に返信するときは、ローカルの口調モデルが引き続き通知します。

外付けキーボードに右側の⌥や⌘がない場合は？

「設定 → 話す → ホットキー」で押しやすいキーの組み合わせに変更できます。
