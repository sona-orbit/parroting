鍵盤上的按鍵

學舌鳥只有語音，沒有注音、英文鍵盤。要打字，按地球鍵切回 Apple 鍵盤。

⇠ ⇢

語音／改寫／翻譯　三個分頁，點一下切換。

AI 改寫　選一個格式（語氣修正、信件格式、條理分明…），說話時就多一顆彩色鈕：按它先用這個格式改寫再貼上，按「完成」照原話貼上。再點一次同一個格式就關掉。格式可以在學舌鳥「設定 › 改寫格式」新增、修改或刪除。

↶ ↷　復原、重做剛貼上的字。

⌫　@　換行　刪除、輸入 @、換行。

標點　左右滑，找更多符號。

全／半　切換全形、半形標點。

‹ ›　游標往左、往右移一格。

左右滑　在鍵盤空白的地方左右滑，也能移動游標。

已經打好的字

改寫與翻譯

結果直接換進輸入框，不會另外跳出預覽。

改寫

拉好滑桿，按「改寫」

  1. 1選取要改的字（或剛說完那一段），切到「改寫」分頁。
  2. 2拉篇幅、正式、語氣、結構四條滑桿。
  3. 3按下方大顆的「改寫」，結果直接換進輸入框。

拉滑桿不會自動改，要按「改寫」才會動。換好時鍵盤會閃一下、輕輕震動；想在輸入框裡也標出改過的字，到「設定 › 鍵盤」打開「改字時在輸入框標一下」（實驗功能）。日文、英文也照原本的語言改。沒選字時，下方那顆是「說一段」，先說再改。想再調就拉好再按一次；不滿意按 ↶ 回到原文。

在學舌鳥 App 裡

設定

詞典、改寫格式、我的資料、文字紀錄可經 iCloud 與 Mac 版共用。

AI 來源

Apple 內建：用 iPhone 上的 Apple Intelligence，免費、不用網路，文字不離開手機。
我的 API key：選一家 AI 服務（Gemini、OpenAI、Claude、OpenRouter、Groq、DeepSeek、通義千問、Kimi、智譜 GLM，或自訂網址），貼上那家的 key；每家怎麼申請，點設定裡的「怎麼申請 … 的 API key？」就有步驟。文字從手機直接送到你選的服務，不經過學舌鳥。

紀錄

在下方的「紀錄」分頁：說過的每一句都留著，可以搜尋，也能看整理前的原文。

改寫格式

四種內建格式都能改、能刪（刪掉的可以加回），也能自己新增。用「比較格式」說一段話，看每種格式寫出來的樣子；打勾的會出現在鍵盤上。和 Mac 共用。

有趣的回報

每週一出週報、每月 1 號出月報：說了多少字、最常說的口頭禪、常聽錯的字、用了哪些格式。設定好 AI，還會多「聊了什麼」「金句」和一段自由發揮。回報好了，鍵盤上的小鳥會亮紫點。只整理在這支手機說的話。

辨識語言

預設跟著系統。講其他語言時，到這裡換。

我的資料

署名、職稱填一次，寫信格式自動帶入。

遇到問題

在 App 裡直接告訴我們。

設定›回報問題

常見卡關

大多數問題都在這四個裡面。

按地球鍵找不到學舌鳥

回到第一次設定的第 2 步，確認有在「新增鍵盤」裡加入學舌鳥。

點麥克風沒反應，或一直跳回 App

確認「允許完整取用」有打開。第一次點麥克風會跳回學舌鳥是正常的，點左上角「◀」回去接著說；在待命時間內再點，就不會再跳。待命時間在學舌鳥「設定 › 待命時間」調整，選「不待命」就每次都會跳。

密碼欄會自動換成 Apple 鍵盤

這是 iOS 的規定，所有第三方鍵盤都一樣。

小鳥顯示「遇到問題」

鍵盤上會出現一條橘色說明，寫出原因（例如 API key 錯、額度用完），點它就打開學舌鳥的 AI 設定照著改。
