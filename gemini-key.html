申請免費的 Gemini API key

學舌鳥的「AI 整理口語」和「改寫」要用 AI 服務。Google 的 Gemini 有長期的免費額度，台灣可以直接申請，一般聽寫和改寫通常夠用。照下面四步做，三分鐘就能開始用。

免費不用綁信用卡只要 Google 帳號
1

打開申請頁並登入

用瀏覽器打開 aistudio.google.com/api-keys，用你的 Google 帳號登入。第一次使用會先問你同意服務條款，勾選後繼續。

直接開這個網址最快；從 AI Studio 首頁找入口容易迷路。新帳號會自動建好一個專案和第一把 key，可以直接跳到第 2 步複製。

在「API Keys」頁按右上角的「Create API key」，名稱和專案都維持預設，再按建立。畫面上會出現一串以 AIza 開頭的文字，按旁邊的複製圖示。

key 就像密碼，不要貼到網路上或傳給別人。不小心外流的話，回到這頁刪掉，再建一把新的就好。

貼進學舌鳥

key 會存在這台 Mac 的鑰匙圈裡。忘了也沒關係，回到 AI Studio 同一頁隨時可以再複製。

你需要知道的

免費版的額度與資料。

免費額度

免費版每分鐘、每天都有次數上限，一般聽寫和改寫通常夠用。用得很多、遇到「額度已用完」時，等一下或隔天就會恢復；想放寬上限，可以在 AI Studio 左側的「Billing」綁定信用卡改成付費方案。Google 會替新綁卡的帳號設每月花費上限，不會突然出現大筆帳單。

你的資料

依 Google 的說明，免費版送出的內容可能被用來改善 Google 的產品；付費版不會。學舌鳥只會送出文字，聲音一律不上傳。如果你常講工作機密或個人資料，可以考慮改用付費方案，或在送出前留意內容。

常見問題

卡住的時候。

「Create API key」按鈕是灰的，按不下去

如果你的 Google 帳號以前用過 Google Cloud，AI Studio 不會自動建立專案。到左側的「Dashboard」→「Projects」按「Import projects」，選一個專案匯入後，再回 API Keys 頁建立。公司或學校帳號也可能沒有權限，換成個人 Google 帳號最簡單。

貼上 key 之後，首頁還是顯示沒設定

確認供應商選的是「Gemini」，key 前後沒有多複製到空白，而且是完整一串以 AIza 開頭的文字。

用一用突然沒有 AI 整理了

多半是免費額度暫時用完。這時學舌鳥會自動改用本機規則，聽寫照常可以用；過一陣子或隔天額度恢復就會回來。

可以用其他 AI 服務嗎？

可以。「AI 改寫」頁的供應商還有 OpenAI、Anthropic、OpenRouter、Groq 等，各自到對方網站申請 key 貼上就好；這些通常要付費。
