Can You Use Mac Dictation Offline? What to Set Up Beforehand

Can you use voice typing on a Mac while flying, passing through a train tunnel, or working somewhere that does not allow audio uploads? It depends on the tool. This article shows how to check whether built-in Dictation processes speech on your Mac, what to set up before using a local speech model offline, and which features still work without internet.

For built-in Dictation, I used Apple's documentation on dictating messages and documents on Mac and macOS feature availability. For Apple Intelligence, I used the Foundation Models developer documentation. I checked these sources on November 18, 2026. Parroting's features and menu names are based on version 0.4.20.

1. The short answer: Offline use depends on two things

  1. Where speech is recognized. If your Mac turns speech into text, you can keep dictating without internet. If audio must go to a server, dictation stops when you disconnect.
  2. What you set up before disconnecting. Download local models first. Choose the languages and AI cleanup method you plan to use. If you discover a missing file after you lose internet, it is too late to download it.

For Taiwanese Mandarin, assume that macOS built-in Dictation needs internet. A voice typing tool with a local model can work offline once you download the model. Before you leave, turn off Wi-Fi and say a few sentences to test it.

2. Built-in Dictation: Check whether your language runs on-device

Apple lists the languages that support on-device Dictation separately. When I checked, the list included Mandarin (China mainland) and Cantonese (Hong Kong), but not Mandarin (Taiwan). That means Dictation in Mandarin (Taiwan) sends audio to Apple's servers for processing and cannot work without internet.

The list can change with macOS updates. Check your own Mac.

  1. Go to the Apple menu → System Settings → Keyboard.
  2. Read the text under Dictation. It tells you whether speech in your current language is processed on-device or sent to a server.
  3. Turn off Wi-Fi, open Notes, and use your Dictation shortcut to say a sentence. If text appears, it works offline.

If you have not enabled Dictation yet, I cover the setup and shortcut in how to turn on Mac voice typing.

3. Local speech models: Do four things before going offline

Voice typing tools with local models recognize speech on your Mac. You still need internet to download the model and language files and complete the initial setup. For Parroting, take these four steps before you leave.

  1. Download a speech model. The first-run guide asks you to download one. To switch later, go to “Settings → Talk → Speech model & language” and download one from “Manage models”. You only need to download it once. Recognition then runs on this Mac, so you can dictate without internet. If the connection drops during a download, select “Retry” to continue where it stopped.
  2. Download any tone model you need. The Chinese tone model is built in. English and Japanese tone models download when you need them. If you often speak English or Japanese, go to “Settings → Tone & context”, find the English or Japanese tone model, and select “Download” before leaving.
  3. Choose how to clean up your text with AI. Parroting has three ways to remove fillers like “um” and “uh” and handle mid-sentence corrections. They behave differently offline. The next section has a table.
  4. Turn off Wi-Fi and test it. Hold right ⌥ ＋ right ⌘ and say “Testing, one, two.” Release the keys. If the text appears at your cursor, you are ready.

4. What still works without internet

Parroting's welcome screen splits features into two columns: “Works offline on this Mac” and “With your own AI API key”. Here is the breakdown.

FeatureWithout internetDetails
Speech recognitionWorksRuns locally after you download the model
Chinese text formattingWorksPunctuation, spaces between Chinese and English, and Traditional or Simplified Chinese output
Dictionary and historyWorkStored on this Mac; the dictionary works without AI
Tone hintsWorkThe Chinese model is built in; download the English or Japanese model first
AI cleanup (cloud service API key)Falls back to local resultsShows a connection notice, then inserts locally processed text
AI cleanup (Apple Intelligence)Depends on system requirementsUses Apple's on-device model; no API key needed
Rewrite panel (change tone, formal email, translation)Needs access to your chosen AICloud services cannot work without internet

There are a few details worth knowing about AI cleanup.

  • Without an API key, Parroting uses local mode. It removes standalone fillers like “um” and “uh” and repeated words on your Mac. Cleaning up a mid-sentence correction requires AI.
  • With a cloud service key but no internet, the floating window tells you it cannot connect and inserts the locally processed result. Your text is still there, just without the AI cleanup.
  • With Apple Intelligence, Parroting calls the on-device model in Apple's documentation (SystemLanguageModel). You do not need a key. You need Apple silicon, macOS Tahoe (26.0) or later, and Apple Intelligence turned on in System Settings.
  • If you run a language model on your Mac, you can go to “Settings → AI” and choose Custom as the provider. Its default URL is the local http://localhost:11434/v1, which points to the model service running on this Mac.

5. Choosing an offline model for a Mac with less memory

Offline voice typing speed mainly depends on the model's size and your Mac's speed. Downloaded models take up disk space. Only the model in use goes into memory, and that memory is released after a period of inactivity.

  • 8 GB of memory and a preference for speed: Start with the default SenseVoice Small (253 MB). It runs smoothly on older Macs, too.
  • Better Chinese accuracy: Try Qwen3-ASR 0.6B (850 MB). The 1.7B model (1.5 GB) is more accurate, but slower and uses more memory.
  • A Taiwanese accent or frequent switching between Chinese and English: Breeze-ASR-25 (1.2 GB) is tuned for this kind of speech, but it is the slowest model on the list.

6. Frequently asked questions

Can I use built-in Mac Dictation for Chinese offline?

It depends on the language. Apple's on-device Dictation list includes Mandarin (China mainland) and Cantonese (Hong Kong), but did not include Mandarin (Taiwan) when I checked in November 2026. Read the text under Dictation in System Settings → Keyboard, or turn off Wi-Fi and test it with a sentence.

Do I need internet the first time I use Parroting?

Yes. You need to download the app and a speech model first. Once the model is downloaded, recognition runs on this Mac and you can dictate without internet.

What happens to AI cleanup without internet?

If you use a cloud service API key, Parroting shows a connection notice and inserts locally processed text instead. If you choose Apple Intelligence, it uses Apple's on-device model. That requires Apple silicon, macOS Tahoe (26.0) or later, and Apple Intelligence turned on.

Does offline voice typing upload my audio?

With a local model, audio is processed only on this Mac. Parroting sends text to your chosen AI service only when you use cloud AI. Regular dictation and tone hints run locally.

Can a Mac with 8 GB of memory use voice typing offline?

Yes. The default SenseVoice Small model is 253 MB, responds quickly, and uses little memory. For better accuracy, try Qwen3-ASR 0.6B (850 MB).
